# ![BeeApiary godło marki](../assets/common/brand/beeapiary-emblem.png){ .home-brand-logo width="780" height="780" } BeeApiary — wagi pasieczne i monitoring pasieki { #beeapiary }

BeeApiary łączy wagi pasieczne z systemem monitorowania pasieki obsługującym GSM, Wi-Fi i Bluetooth. Wagi wraz z czujnikami i aplikacją pomagają obserwować stan uli, analizować zmiany i prowadzić dziennik zarówno bezpośrednio w pasiece, jak i zdalnie. Aplikacji można też używać samodzielnie, bez wag.

Jeden zestaw może działać samodzielnie jako waga pasieczna BeeApiary, a wraz z czujnikami i aplikacją tworzyć inteligentny ul BeeApiary. Kilka takich uli połączonych w aplikacji z cyfrowym dziennikiem tworzy inteligentną pasiekę BeeApiary. Różne sposoby dostępu do danych, długoterminowe notatki, pomiary i zdarzenia dają pełny obraz życia pasieki i pomagają pszczelarzowi lepiej rozumieć swoje pszczoły.

## Twoje dane pozostają pod Twoją kontrolą

- Wszystkie dane są przechowywane lokalnie. Nie ma obowiązkowego połączenia z serwerami zewnętrznymi, dlatego nie jest wymagana karta SIM. ([Pobierz archiwum pomiarów](guides/download-archive.md))
- Dane dostępne są bezpośrednio w pasiece poprzez lokalną sieć Wi-Fi, dzięki czemu nie jest wymagana karta SIM. ([Połącz się z punktem dostępowym wagi](guides/configure-local-wifi.md))
- Zdalny dostęp przez Internet możliwy jest poprzez lokalną sieć Wi-Fi na terenie pasieki, dzięki czemu nie jest wymagana osobna karta SIM do każdego urządzenia. ([Skonfiguruj transmisję poprzez pasieczną sieć Wi-Fi](guides/configure-wifi-sync.md))
- Dane można uzyskać bezpośrednio przez Bluetooth, gdy znajdziesz się w pobliżu urządzenia. Synchronizacja odbywa się automatycznie, więc nie jest wymagana karta SIM. ([Skonfiguruj synchronizację Bluetooth](guides/configure-bluetooth-sync.md))
- Dostęp za pośrednictwem operatora komórkowego również pozostaje dostępny i nie wymaga mobilnego Internetu. Wystarczy karta SIM z planem minimalnym. ([Skonfiguruj GSM i SMS](guides/configure-gsm.md))
