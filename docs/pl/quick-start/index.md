# Szybki start

Wybierz, jak chcesz używać BeeApiary:

- [Konfiguracja systemu i GSM](full-system.md) — zainstaluj kartę micro-SIM i odbierz pierwszą wiadomość SMS; w razie potrzeby dodaj aplikację.
- [Zainstaluj aplikację](app-only.md) — rozpocznij bez fizycznego urządzenia lub skorzystaj z trybu demonstracyjnego.
- [Punkt dostępowy wagi](local-wifi.md) — otwórz interfejs sieciowy urządzenia, gdy jesteś w pobliżu.

!!! warning "Zanim zaczniesz"
    Nowe urządzenie jest dostarczane skalibrowane. Nie należy wyjmować baterii, tarować ani kalibrować wagi bez szczególnej potrzeby i bez uprzedniego przeczytania odpowiednich instrukcji.
