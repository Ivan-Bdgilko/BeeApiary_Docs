# Łączenie się z urządzeniem poprzez GSM

!!! warning
    Użyj karty micro-SIM. Wyłącz wcześniej ochronę PIN-u karty SIM.

    ![Porównanie formatów kart SIM](../../assets/en/quick-start/gsm/micro-sim-format-comparison.png){ .doc-photo }

1. [Zainstaluj BeeApiary aplikacja](app-only.md) jeśli potrzeba. Nie jest wymagane odbieranie zwykłych wiadomości SMS. Jeśli aplikacja musi automatycznie przetwarzać dane pomiarowe z wiadomości SMS, zgoda na SMS jest obowiązkowa.
2. Otwórz pokrywę modułu gromadzenia danych.

    ![Otwórz jednostkę zbierającą dane](../../assets/common/device/installation/open-data-collection-unit.png){ .doc-photo }

3. Włóż kartę micro-SIM do odpowiedniego gniazda.

    Prawidłowa pozycja karty:

    ![Prawidłowo włożona karta micro SIM](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    Włóż kartę SIM i delikatnie ją dociśnij, aż zostanie prawie całkowicie wsunięta w gniazdo i usłyszysz lekkie kliknięcie potwierdzające, że karta została zablokowana na swoim miejscu:

    ![micro-SIM zablokowany w gnieździe](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

4. Aktywuj lub uruchom ponownie urządzenie w ten sam sposób: krótko przytrzymaj klucz magnetyczny przy markowym oznaczeniu z tyłu jednostki głównej.

    ![BeeApiary klucz magnetyczny](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

    ![Markowy celownik z kluczem magnetycznym na jednostce głównej](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

5. Poczekaj około minuty.
6. Potwierdź, że pierwsza wiadomość SMS dotrze na wstępnie skonfigurowany numer.

Gotowe: urządzenie zostało aktywowane lub zrestartowane i może wysyłać pomiary poprzez sieć GSM.

Jeżeli numer właściciela nie został jeszcze skonfigurowany, [skonfiguruj numer poprzez lokalną sieć Wi-Fi](../guides/configure-gsm.md).
