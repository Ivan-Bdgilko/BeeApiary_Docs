# Jak zainstalować aplikację BeeApiary

Pełną instrukcję instalacji i nadawania uprawnień znajdziesz na stronie [Instalacja aplikacji BeeApiary](../app/installation.md).

Aplikacja może działać jako samodzielny dziennik lub odbierać dane z wagi. Do przetwarzania SMS-ów z wagi wymagane jest uprawnienie do SMS-ów.
