# Jak tarować wagę

Tarowanie nie uwzględnia ciężaru platformy lub innej trwałej konstrukcji.

1. Połącz się z interfejsem internetowym urządzenia BeeApiary wagi do ula.
2. Otwórz **Ustawienia ogólne → Ustawienia wagi**.
3. Jeśli znasz wagę tary, wprowadź ją w gramach i wybierz **Ustaw wagę tary**.
4. Alternatywnie zostaw wymaganą konstrukcję na czujnikach i wybierz opcję, która przyjmuje wartość bieżącą jako zero.
5. Sprawdź odczyt po zakończeniu operacji.

Wynik: urządzenie odejmie od kolejnych pomiarów zadaną tarę. Tarowanie nie jest kalibracją.
