# Stan ula

stan ula umożliwia rejestrowanie wyników inspekcji, w tym informacji o królowej, sile rodziny, czerwiu, ramkach i innych ważnych wskaźnikach. Aby otworzyć ten ekran z poziomu [ekran główny aplikacji](main-screen.md), przesuń w lewo.

![Ekran aplikacji do dodawania lub aktualizowania stanu ula](../../assets/en/app/hive-state/hive-state-editor.jpg){ .doc-screenshot }

## Dodawanie i aktualizacja stanu ula

Wybrany ul oraz data i godzina zapisu pojawiają się w górnej części ekranu.

- **Dodaj nowy stan** tworzy oddzielny rekord stanu ula dla wybranej daty i godziny.
- **Zaktualizuj bieżący stan** zapisuje zmiany w bieżącym rekordzie bez tworzenia kolejnego stanu.

## Pola stanu ula

| Pole | Co wpisać |
|---|---|
| **Rok królowej** | Rok, w którym wychowano lub sprowadzono królową. |
| **typ ula** | Konstrukcja ula ze skonfigurowanej listy [typy uli](hive-types.md). |
| **Królowa (rasa i stan)** | Rasa królowej i krótka ocena jej aktualnego stanu. |
| **opis stanu ula** | Swobodny opis wyników kontroli. |
| **Wielkość kolonii** | Względna ocena siły kolonii za pomocą wagi. |
| **Zamknięty lęg** | Względna ocena ilości czerwiu czaprakowego. |
| **Liczba larw** | Względna ocena liczby larw. |
| **Liczba jaj** | Względna ocena liczby jaj. |
| **Liczba klatek** | Całkowita liczba klatek w ulu. |
| **Super liczba klatek** | Liczba zainstalowanych superramek. |
| **Suchy grzebień** | Liczba klatek z narysowanym grzebieniem. |
| **Liczba ram fundamentowych** | Liczba ram wyposażonych w fundament. |
| **Poziom agresji** | Względna ocena agresji kolonii. |
| **Poziom roju** | Względna ocena stanu roju kolonii. |
| **Wydajność królowej** | Względna ocena osiągnięć królowej. |
| **Poziom Varroa** | Względna ocena inwazji warrozy. |

Pola ze skalą wagową służą do ocen względnych, natomiast pola ramkowe służą do zliczeń. Wprowadź tylko te informacje, które są niezbędne do prowadzenia Twojej pasieki.

!!! note "Wprowadzanie głosowe"
    Nie musisz wpisywać pola oznaczonego ikoną mikrofonu. Podyktuj opis, a aplikacja zamieni Twoją mowę na tekst. Spowoduje to utworzenie edytowalnego, przeszukiwalnego i kopiowalnego tekstu zamiast zapisywania pliku audio.

 [Kolejność pola stanu ula](hive-state-settings.md) menu określa, które pola pojawiają się na ekranie i w jakiej kolejności.
