# Ustawienia aplikacji

 **Ustawienia** strona to menu nadrzędne zawierające opcje wyświetlania i zachowania aplikacji. Każdy element otwiera oddzielny ekran podrzędny.

![BeeApiary menu ustawień aplikacji](../../../assets/en/app/settings/app-settings-menu.jpg){ .doc-screenshot }

| Pozycja menu | Przeznaczenie |
|---|---|
| **Kolejność na ekranie głównym** | Otwiera się [wybór danych i wykresów](../chart-settings.md). Te ustawienia określają, które kafelki mają być wyświetlane i ich kolejność na ekranie głównym, a w przypadku wartości liczbowych – które wykresy są wyświetlane i ich kolejność na ekranie wykresów. |
| **kolejność pól stanu ula** | Otwiera [ustawienia pola stanu ula](../hive-state-settings.md). |
| **Kolejność ekranów pogodowych** | Otwiera [ustawienia danych prognozy pogody](../weather-settings.md). |
| **Dodatkowe ustawienia** | Otwiera się [dodatkowe opcje zachowania aplikacji](../additional-settings.md), w tym wyświetlanie zdarzeń i obsługa Bluetooth. |
| **Urządzenia i ule** | Zarządza listą profili. Dodawanie [BeeApiary wagi do ula](../add-device.md) i [ul](../add-hive.md) są opisane osobno; pełny opis tego ekranu jest wciąż w przygotowaniu. |
| **typy uli** | Otwiera [lista typów uli](../hive-types.md) używany w pasiece. |
| **Nazwy czujników T** | Umożliwia przypisanie przejrzystych nazw kanałom temperaturowym. Szczegółowy opis zostanie dodany po oddzielnym przejrzeniu tego ekranu. |
| **Lista tagów NFC** | Pokazy [urządzenia i ule połączone za pomocą NFC](../nfc-settings.md#linked-nfc-tags). |
| **Akcja NFC** | Wybiera [akcja wykonywana po rozpoznaniu tagu NFC](../nfc-settings.md#nfc-action). |
