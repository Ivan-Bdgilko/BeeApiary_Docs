# Dodatkowe narzędzia

 **Dodatkowe narzędzia** podmenu zawiera polecenia służące do tworzenia kopii zapasowych danych i diagnostyki serwisowej.

![Dodatkowe menu narzędzi w BeeApiary aplikacja](../../assets/en/app/additional-tools/additional-tools-menu.png){ .doc-screenshot }

| Polecenie | Przeznaczenie |
|---|---|
| **Zapisz dane (kopia zapasowa)** | Tworzy kopię zapasową bazy danych aplikacji. |
| **Przywróć dane** | Przywraca dane aplikacji z wcześniej utworzonej kopii zapasowej. |
| **Zapisz plik dziennika** | Zapisuje plik dziennika usług, który można wysłać do pomocy technicznej w celu przeprowadzenia diagnostyki. |

!!! warning "Zachowaj aktualną kopię zapasową"
    Przed przywróceniem upewnij się, że wybrałeś wymaganą kopię danych. Zapisz bieżącą kopię zapasową osobno, jeśli konieczne będzie jej późniejsze przywrócenie.
