# Wydarzenia i notatki

Zdarzenia pomagają zachować historię pracy, inspekcji i obserwacji każdego ula. Aby otworzyć listę wydarzeń z poziomu [ekran główny aplikacji](main-screen.md), przesuń w prawo.

## Lista wydarzeń

Na ekranie widoczny jest wybrany ul i zapisane w nim zdarzenia. Każdy wpis zawiera ikonę typu, nazwę, znacznik koloru oraz datę i godzinę. Kliknij **Wstaw** aby utworzyć wydarzenie, lub wybierz istniejący wpis, aby go edytować.

![Lista wydarzeń dla wybranego ula w aplikacji](../../assets/en/app/events-and-notes/events-list.jpg){ .doc-screenshot }

Możesz także tworzyć przyszłe zaplanowane wydarzenia. Aplikacja powiadamia Cię z wyprzedzeniem, aby zaplanowane prace nie zaginęły wśród bieżących zapisów.

## Dodawanie lub edycja wydarzenia

![Ekran edycji wydarzenia w aplikacji](../../assets/en/app/events-and-notes/event-editor.jpg){ .doc-screenshot }

| Elementu | Przeznaczenie |
|---|---|
| **Typ wydarzenia** | Określa cel, ikonę i kolor znacznika wpisu. |
| **Data i godzina** | Rejestruje, kiedy miało miejsce zdarzenie lub kiedy przypada termin zaplanowanych prac. |
| **Krótki opis** | Nadaje zakończonej lub planowanej akcji krótką nazwę. |
| **Szczegółowy opis** | Przechowuje dodatkowe informacje, wyniki kontroli lub notatki. |
| **Zapisz** | Zapisuje nowe wydarzenie lub zmiany. |
| **Usuń** | Usuwa otwarte wydarzenie. |

!!! note "Wprowadzanie głosowe"
    Pole oznaczone ikoną mikrofonu obsługuje dyktowanie. Aplikacja konwertuje Twoją mowę na tekst, który możesz później edytować, wyszukiwać i kopiować. Nie zapisuje nagrania audio.

## Typy zdarzeń

![Wybór typu wydarzenia w aplikacji](../../assets/en/app/events-and-notes/event-type-options.jpg){ .doc-screenshot }

| Wpisz | Kiedy go używać |
|---|---|
| **Kontrola** | Rejestrowanie wyników inspekcji ula. |
| **Dodano** | Aby wskazać, że coś zostało dodane do ula. |
| **Usunięto** | Aby wskazać, że coś zostało usunięte z ula. |
| **Ostrzeżenie** | Na wydarzenia wymagające szczególnej uwagi. |
| **Obserwacja** | Aby zarejestrować zaobserwowany stan lub zdarzenie. |

Typy wydarzeń mają różne kolory i ikony. Na [wykresy](charts.md), zdarzenia są wyświetlane ze znacznikami czasu i ułożone według czasu wystąpienia. Pomaga to porównać pracę pasieki ze zmianami masy, temperatury i innymi pomiarami.
