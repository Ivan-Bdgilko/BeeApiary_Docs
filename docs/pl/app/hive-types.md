# Rodzaje uli

 **typy uli** pozwala dostosować listę typów korpusów uli do tych używanych w pasiece. Aplikacja zawiera kilka przykładowych typów, ale początkowa lista nie obejmuje wszystkich konstrukcji uli.

Większość pasieki wykorzystuje od jednego do pięciu typów uli, więc początkowa lista zapewnia dodatkową pojemność do typowego użytku. Możesz dowolnie zmieniać istniejące typy lub poszerzać listę, aby dopasować ją do swojej pasieki.

1. Otwórz **Menu główne → Ustawienia → typy uli**.
2. Znajdź żądany typ na liście.
3. Kliknij jego kafelek, aby skonfigurować sposób jego używania w aplikacji.

![Lista typów uli w BeeApiary aplikacja](../../assets/en/app/hive-types/hive-types-list.jpg){ .doc-screenshot }

To ustawienie należy do opisów uli w aplikacji i nie zmienia konfiguracji sprzętowej ula BeeApiary wagi do ula.
