# Tagi i akcje NFC

Ustawienia NFC składają się z dwóch powiązanych ze sobą ekranów: listy powiązanych tagów oraz akcji, jaką aplikacja wykonuje po rozpoznaniu ula.

## Co to jest tag NFC?

Tag NFC to mały identyfikator elektroniczny. Może to być breloczek, moneta, naklejka, standardowa karta NFC lub specjalna karta do ula. Przywieszkę przymocuj do ula w miejscu dogodnym do skanowania, np. pod dachem lub na ścianie.

Gdy zbliżysz telefon z obsługą NFC do tagu, aplikacja szybko zidentyfikuje konkretny ul i wykona wybraną akcję: otworzy szczegóły ula, jego status lub zdarzenia lub natychmiast rozpocznie tworzenie wydarzenia za pomocą poleceń głosowych.

Wystarczy raz połączyć kompatybilny tag z profilem ula i pozostawić go w ulu. Skraca to czas potrzebny na znalezienie odpowiedniego profilu i pomaga zachować pełniejszą historię bez konieczności oddzielnych papierowych notatek.

!!! info "Notatka głosowa staje się tekstem"
    Aplikacja nie tylko zapisuje nagranie głosowe: konwertuje podyktowaną notatkę na tekst. Jest to szczególnie wygodne podczas pracy w rękawiczkach ochronnych, podczas prac hodowlanych lub podczas sekwencyjnej kontroli wielu uli. Możesz później przeglądać, wyszukiwać, przetwarzać i kopiować tekst, jeśli zajdzie taka potrzeba.

## Połączone tagi NFC { #linked-nfc-tags }

Otwórz **Menu główne → Ustawienia → Lista tagów NFC** aby wyświetlić urządzenia lub ule, które aplikacja może zidentyfikować za pomocą NFC.

![Lista urządzeń i uli połączonych za pomocą NFC](../../assets/en/app/nfc-settings/linked-nfc-tags.jpg){ .doc-screenshot }

Lista pokazuje nazwę i identyfikator każdego połączonego profilu. Dotknięcie odpowiedniego kafelka usuwa łącze NFC.

!!! info "Lista urządzeń i uli"
    Na liście urządzeń i uli osobna ikona NFC wskazuje, że tag jest powiązany. Bezpośredni link do pełnego opisu tego ekranu zostanie dodany po zakończeniu jego sprawdzania.

## Działanie po rozpoznaniu { #nfc-action }

Otwórz **Menu główne → Ustawienia → Akcja NFC** i wybierz, co aplikacja ma otworzyć po rozpoznaniu tagu NFC.

![Wybór akcji wykonywanej po rozpoznaniu tagu NFC](../../assets/en/app/nfc-settings/nfc-action-settings.jpg){ .doc-screenshot }

Dostępne akcje:

- **Otwórz ul**;
- **Stan otwartego ula**;
- **Otwarta impreza w ulu**;
- **Wydarzenie + nagranie głosu**.

Ostatnia opcja otwiera natychmiast tworzenie zdarzeń za pomocą głosu po zidentyfikowaniu ula.
