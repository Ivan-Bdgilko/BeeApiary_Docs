# Dodaj ul

Utwórz profil ula bez fizycznej wagi ula, aby prowadzić dziennik, rejestrować jego status, dodawać notatki oraz zapisywać zaplanowane i zakończone zdarzenia. W tym scenariuszu nie jest wymagana waga do ula, karta SIM ani pozwolenie na przetwarzanie SMS-ów.

1. Otwórz **Menu główne → Dodaj urządzenie lub ul**.
2. Na **Urządzenia i ule** ekranie, dotknij **Dodaj ul**.
3. Wpisz nazwę, która ułatwi Ci znalezienie tego ula.
4. Kliknij **Wstaw**.

    ![Formularz dodawania profilu ula bez wagi ula](../../assets/en/app/add-hive/add-hive-form.jpg){ .doc-screenshot }

Po zapisaniu profil pojawi się na udostępnionej liście urządzeń i uli. Użyj [Stan ula](hive-state.md) i [Wydarzenia i notatki](events-and-notes.md) budować swoją historię na przestrzeni czasu.
