# Konserwacja

- Po dłuższym przechowywaniu sprawdź napięcie akumulatora. Jeśli jest poniżej `3,5 В`, postępuj zgodnie z [procedura odzyskiwania](../troubleshooting/recovery-after-storage.md); w przeciwnym razie naładuj baterię przez USB typu C.
- Nie wyjmuj baterii, jeśli nie jest to konieczne. Po odłączeniu sprawdź czas urządzenia.
- Okresowo sprawdzaj obudowę pod kątem kondensacji, obecności owadów i zanieczyszczeń.
- Sprawdź kartę microSD, jeśli potrzebujesz lokalnych archiwów i dzienników serwisowych.
- Aktualizuj oprogramowanie sprzętowe wyłącznie poprzez kontrolowaną procedurę: [Aktualizowanie urządzenia](../guides/update-device.md).

!!! note "Ładowanie"
    Urządzenie nie obsługuje szybkiego ładowania, w tym USB Power Delivery (PD). Do ładowania użyj standardowego źródła zasilania z portem USB typu A i kablem USB typu A–USB typu C, a nie kabla USB typu C–USB typu C.

Pomiary rdzeniowe i transmisja danych mogą działać bez karty microSD, ale archiwum i logi na karcie będą wówczas niedostępne.

Przed końcem sezonu przejrzyj [zasady użytkowania i przechowywania zimą](winter-use-and-storage.md).
