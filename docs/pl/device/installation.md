# Jak zamontować wagę pasieczną pod ulem { #_1 }

Umieść jednostkę główną w osłoniętym miejscu, a czujniki masy na stabilnych podporach.

1. Wybierz osłonięte miejsce pod daszkiem lub pokrywą ula.
2. Umieść jednostkę główną tak, aby ograniczyć bezpośrednie działanie słońca, deszczu i śniegu.
3. Ustaw [czujniki masy](sensors.md) na stabilnych podporach w jednej płaszczyźnie poziomej.
4. Rozmieść czujniki temperatury zgodnie z celem obserwacji.

!!! danger
    Nie umieszczaj urządzenia ani anteny zewnętrznej w najwyższym punkcie pasieki: uderzenie pioruna może spowodować nieodwracalne uszkodzenia.

Więcej: [Rozmieszczenie](placement.md) i [Czujniki](sensors.md).
