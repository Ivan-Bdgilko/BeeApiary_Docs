# Elektroniczne wagi do uli BeeApiary — dane techniczne { #_1 }

Poniżej specyfikacja ww BeeApiary wagi ula: zakresy pomiarowe, moc, kanały transmisji i lokalna pamięć danych. Porównując wagi dla swojej pasieki, należy wziąć pod uwagę konfigurację urządzenia i warunki pracy, ponieważ mają one wpływ na żywotność baterii.

| Parametr | Wartość |
|---|---|
| Waga | 0–200 kg, deklarowana dokładność ±0,1 kg |
| Temperatura | −20 do +50°C, deklarowana rozdzielczość 0,1°C |
| Wilgotność, opcjonalnie | 0–100%, rozdzielczość 1% |
| Ciśnienie, opcjonalne | 50–950 mmHg, deklarowana dokładność ±1 mmHg |
| Moc | 1 lub 2 ogniwa 18650 |
| Ładowanie | USB typu C lub panel słoneczny |
| Transmisja | GSM, Wi-Fi, BLE |
| Magazyn lokalny | microSD |
| Waga zestawu | około 0,5 kg |

Żywotność baterii zależy od konfiguracji urządzenia, stanu baterii, zasięgu sieci GSM i liczby wysłanych wiadomości SMS. W przypadku zalecanej konfiguracji wynosi to co najmniej pięć miesięcy, ale nie jest to gwarantowane we wszystkich warunkach.
