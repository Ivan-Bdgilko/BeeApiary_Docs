# ![BeeApiary emblema da marca](../assets/common/brand/beeapiary-emblem.png){ .home-brand-logo width="780" height="780" } BeeApiary — balanças para colmeias e monitoramento do apiário { #beeapiary }

BeeApiary combina balanças para colmeias e um sistema de monitoramento do apiário com suporte a GSM, Wi-Fi e Bluetooth. Junto com os sensores e o aplicativo, as balanças ajudam a acompanhar o estado das colmeias, analisar mudanças e manter um diário tanto no apiário quanto remotamente. O aplicativo também pode ser usado separadamente, sem balanças.

Um conjunto pode funcionar de forma autônoma como balança BeeApiary e, junto com os sensores e o aplicativo, formar uma colmeia inteligente BeeApiary. Várias dessas colmeias, reunidas no aplicativo com um diário digital, formam um apiário inteligente BeeApiary. As diferentes formas de acesso aos dados, as notas de longo prazo, as medições e os eventos oferecem uma visão completa da vida do apiário e ajudam o apicultor a compreender melhor suas abelhas.

## Seus dados permanecem sob seu controle

- Todos os dados são armazenados localmente. Não há conexão obrigatória com servidores externos, portanto não é necessário cartão SIM. ([Baixe o arquivo de medição](guides/download-archive.md))
- Os dados estão disponíveis diretamente no apiário através de uma rede Wi-Fi local, portanto não é necessário cartão SIM. ([Conecte-se ao ponto de acesso da balança](guides/configure-local-wifi.md))
- O acesso remoto pela Internet é possível através da rede Wi-Fi local do apiário, portanto não é necessário um cartão SIM separado para cada dispositivo. ([Configure a transmissão através da rede Wi-Fi do apiário](guides/configure-wifi-sync.md))
- Os dados podem ser obtidos diretamente via Bluetooth quando você estiver próximo ao dispositivo. A sincronização acontece automaticamente, portanto, nenhum cartão SIM é necessário. ([Configurar a sincronização Bluetooth](guides/configure-bluetooth-sync.md))
- O acesso através de uma operadora móvel também permanece disponível e não requer Internet móvel. Um cartão SIM com plano mínimo é suficiente. ([Configurar GSM e SMS](guides/configure-gsm.md))
