# Adicione balanças ou uma colmeia

O **Dispositivos e colmeias** tela permite que você:

- adicionar físico BeeApiary balanças de colmeia para perfil de colmeia;
- crie um perfil de colmeia sem nenhum equipamento;
- inicie uma colmeia de demonstração com balanças e dados de teste para explorar o aplicativo.

![Opções para adicionar BeeApiary balanças, uma colmeia ou dados de teste](../../../assets/en/app/add-device-or-hive/add-scales-hive-or-test-data.jpg){ .doc-screenshot }

## BeeApiary Balanças para colmeias

O **Adicionar dispositivo** botão cria um perfil de colmeia vinculado ao físico BeeApiary balanças de colmeia. Este perfil pode receber automaticamente peso, temperatura e outras leituras disponíveis.

Continuar com [Adicionar BeeApiary Balanças para colmeias](../add-device.md). Você pode comparar GSM, uma conexão Wi-Fi direta, a rede Wi-Fi do apiário e Bluetooth em [Recebendo dados no aplicativo](../../system/connectivity.md).

## colmeia Sem balança

O **Adicionar colmeia** O botão cria um perfil separado sem balanças físicas. Você pode usá-lo para manter um diário, descrever o [status de colmeia](../hive-state.md), adicione notas e grave [eventos](../events-and-notes.md).

Continuar com [Adicione uma colmeia](../add-hive.md).

## Teste colmeia com balança simulada

O **Adicionar dados de teste** O botão cria uma colmeia de demonstração com balanças simuladas de colmeia. O aplicativo gera dados semelhantes a leituras reais, permitindo que você explore a tela inicial, gráficos, status da colmeia e eventos e trabalhe com eles como faria com um perfil vinculado a balanças reais inteligentes.

Os valores de teste servem apenas para demonstrar o aplicativo e não são medições reais.
