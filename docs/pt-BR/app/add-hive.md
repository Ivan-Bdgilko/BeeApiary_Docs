# Adicione uma colmeia

Crie um perfil de colmeia sem balanças físicas de colmeia para manter seu diário, registrar seu status, adicionar notas e salvar eventos planejados e concluídos. Este cenário não requer balança de colmeia, cartão SIM ou permissão para processar SMS.

1. Abrir **Menu principal → Adicionar dispositivo ou colmeia**.
2. No **Dispositivos e colmeias** tela, toque **Adicionar colmeia**.
3. Digite um nome que o ajudará a encontrar esta colmeia facilmente.
4. Toque **Inserir**.

    ![Formulário para adicionar um perfil de colmeia sem balança de colmeia](../../assets/en/app/add-hive/add-hive-form.jpg){ .doc-screenshot }

Após salvar, o perfil aparece na lista compartilhada de dispositivos e colmeias. Usar [colmeia Status](hive-state.md) e [Eventos e Notas](events-and-notes.md) construir sua história ao longo do tempo.
