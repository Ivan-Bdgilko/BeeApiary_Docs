# Configurações adicionais do aplicativo

Configurações adicionais controlam a filtragem de dados, a aparência do aplicativo, a exibição de eventos e a sincronização local via Bluetooth.

![Configurações adicionais no BeeApiary Aplicativo Android](../../assets/en/app/additional-settings/app-additional-settings.jpg){ .doc-screenshot }

| Configuração | Função |
|---|---|
| **Filtrar picos altos** | Remove picos de medição acentuados ocasionais do display. |
| **Ver eventos** | Mostra eventos registrados para a colmeia. |
| **Eventos acima dos gráficos** | Afeta apenas a visualização gráfica e controla a ordem das camadas: os eventos são desenhados sobre gráficos ou os gráficos são desenhados sobre eventos, dependendo do estado da chave. |
| **Modo noturno permanente** | Mantém o tema escuro do aplicativo sempre ativado. |
| **Mostrar dicas** | Mostra painéis de ajuda nas telas dos aplicativos. |
| **Procure dispositivos BLE** | Permite que o aplicativo encontre nas proximidades BeeApiary balanças de colmeia e receber dados disponíveis delas via Bluetooth. Para uma operação correta, [**BLE info**](../device/additional-settings.md) deve estar habilitado em cada balança que você deseja sincronizar. |
| **História do BLE** | Recebe um histórico de medições mais longo junto com os dados atuais via Bluetooth, até uma semana dentro do histórico disponível no dispositivo. Isso é útil se você visitar o apiário uma vez por semana. |

Para as duas últimas configurações, siga o completo [Configurar a sincronização Bluetooth](../guides/configure-bluetooth-sync.md) guia.

!!! note "Não confunda as duas telas"
    Esta página descreve as configurações do aplicativo Android. Opções de hardware e canais de comunicação do BeeApiary balanças de colmeia são descritas em [Configurações adicionais do dispositivo](../device/additional-settings.md).
