# Adicionar balanças para colmeias BeeApiary

Adicionar BeeApiary balanças de colmeia para vincular o perfil da colmeia ao equipamento físico e receber leituras automáticas. Os canais de dados disponíveis e seus requisitos são descritos em [Recebendo dados no aplicativo](../system/connectivity.md).

## Adicione as balanças

1. Abrir **Menu principal → Adicionar dispositivo ou colmeia**.
2. No **Dispositivos e colmeias** tela, toque **Adicionar dispositivo**.
3. Insira um nome claro para a colmeia ou balança de colmeia.
4. Se pretende receber dados via GSM, insira o número do cartão SIM instalado na balança de colmeia.

    ![Formulário para adicionar BeeApiary balanças de colmeia](../../assets/en/app/add-device/add-scales-form.jpg){ .doc-screenshot }

5. Toque **Inserir**.

Após salvar, o perfil aparece na lista de dispositivos e colmeias. Os dados das balanças físicas aparecerão após a configuração e a primeira troca bem-sucedida através de um dos [canais suportados](../system/connectivity.md).

## Adicionar usando um cartão NFC

Você pode adicionar balanças de colmeia quando o aplicativo reconhecer um cartão NFC. Nesse caso, o aplicativo cria o perfil e vincula o cartão a ele ao mesmo tempo.

1. Segure o cartão NFC próximo ao telefone.
2. Quando questionado se deseja usar o cartão como identificador de colmeia, selecione a ação necessária:
   - **Link para existente** — selecione um perfil que já foi criado;
   - **Adicionar novo** — crie um novo perfil com este link NFC.

    ![Selecionando como vincular um cartão NFC reconhecido](../../assets/en/app/add-device/nfc-card-binding-choice.jpg){ .doc-screenshot }

3. Depois de selecionar **Adicionar novo**, insira um nome e, para GSM, o número do cartão SIM instalado na balança de colmeia.
4. Toque **Inserir**.

    ![Adicionando BeeApiary balanças de colmeia com link de cartão NFC](../../assets/en/app/add-device/add-scales-with-nfc-form.jpg){ .doc-screenshot }

Para obter mais informações sobre identificação de colmeias e ações disponíveis, consulte [Tags e ações NFC](nfc-settings.md).
