# Tipos de colmeia

O **tipos de colmeia** A tela permite adaptar a lista de tipos de corpo de colmeia aos usados em seu apiário. O aplicativo inclui vários tipos de amostra, mas a lista inicial não se destina a cobrir todos os projetos de colmeias.

A maioria dos apiários usa entre um e cinco tipos de corpo de colmeia, portanto a lista inicial fornece alguma capacidade extra para uso típico. Você pode alterar livremente os tipos existentes ou estender a lista para corresponder ao seu apiário.

1. Abrir **Menu principal → Configurações → tipos de colmeia**.
2. Encontre o tipo necessário na lista.
3. Toque no bloco para configurar como ele será usado no aplicativo.

![Lista de tipos de colmeias no BeeApiary aplicativo](../../assets/en/app/hive-types/hive-types-list.jpg){ .doc-screenshot }

Esta configuração pertence às descrições da colmeia no aplicativo e não altera a configuração de hardware do BeeApiary balanças de colmeia.
