# Eventos e Notas

Os eventos ajudam a manter um histórico de trabalho, inspeções e observações de cada colmeia. Para abrir a lista de eventos no [tela inicial do aplicativo](main-screen.md), deslize para a direita.

## Lista de eventos

A tela mostra a colmeia selecionada e seus eventos salvos. Cada entrada contém um ícone de tipo, nome, marcador colorido e data e hora. Toque **Inserir** para criar um evento ou selecione uma entrada existente para editá-la.

![Lista de eventos para a colmeia selecionada no aplicativo](../../assets/en/app/events-and-notes/events-list.jpg){ .doc-screenshot }

Você também pode criar eventos agendados futuros. O aplicativo avisa com antecedência para que o trabalho planejado não se perca entre os registros atuais.

## Adicionar ou editar um evento

![Tela de edição de eventos no aplicativo](../../assets/en/app/events-and-notes/event-editor.jpg){ .doc-screenshot }

| Elemento | Função |
|---|---|
| **Tipo de evento** | Determina a finalidade, o ícone e o marcador de cor da entrada. |
| **Data e hora** | Registra quando o evento ocorreu ou quando o trabalho planejado está vencido. |
| **Breve descrição** | Dá um nome abreviado à ação concluída ou planejada. |
| **Descrição detalhada** | Armazena informações adicionais, resultados de inspeção ou uma nota. |
| **Salvar** | Salva um novo evento ou suas alterações. |
| **Excluir** | Exclui o evento aberto. |

!!! note "Entrada de voz"
    Um campo marcado com um ícone de microfone oferece suporte ao ditado. O aplicativo converte sua fala em texto que você pode editar, pesquisar e copiar posteriormente. Não salva uma gravação de áudio.

## Tipos de eventos

![Selecionando um tipo de evento no aplicativo](../../assets/en/app/events-and-notes/event-type-options.jpg){ .doc-screenshot }

| Tipo | Quando usar |
|---|---|
| **Inspeção** | Para registrar os resultados de uma inspeção de colmeia. |
| **Adicionado** | Para indicar que algo foi adicionado à colmeia. |
| **Removido** | Para indicar que algo foi retirado da colmeia. |
| **Aviso** | Para eventos que requerem atenção especial. |
| **Observação** | Para registrar uma condição ou ocorrência observada. |

Os tipos de eventos têm cores e ícones diferentes. No [gráficos](charts.md), os eventos aparecem com carimbos de data/hora e são posicionados de acordo com o momento em que ocorreram. Isso ajuda você a comparar o trabalho do apiário com mudanças de peso, temperatura e outras medidas.
