# Tags e ações NFC

As configurações de NFC consistem em duas telas relacionadas: a lista de tags vinculadas e a ação que o aplicativo executa após reconhecer uma colmeia.

## O que é uma etiqueta NFC?

Uma etiqueta NFC é um pequeno identificador eletrônico. Pode ser um chaveiro, uma moeda, um adesivo, um cartão NFC padrão ou um cartão especial para colmeia. Fixe a etiqueta na colmeia em um local conveniente para digitalização, como sob o telhado ou na parede.

Quando você segura um telefone habilitado para NFC próximo à etiqueta, o aplicativo identifica rapidamente a colmeia específica e executa a ação selecionada: abre os detalhes, status ou eventos da colmeia ou começa imediatamente a criar um evento usando entrada de voz.

Você só precisa vincular uma etiqueta compatível ao perfil da colmeia uma vez e deixá-la na colmeia. Isto reduz o tempo necessário para encontrar o perfil correto e ajuda a manter um histórico mais completo sem anotações em papel separadas.

!!! info "Uma nota de voz torna-se texto"
    O aplicativo faz mais do que salvar uma gravação de voz: ele converte a nota ditada em texto. Isto é especialmente conveniente quando se trabalha com luvas de proteção, durante o trabalho de criação ou durante a inspeção de muitas colmeias em sequência. Posteriormente, você pode revisar, pesquisar, processar e copiar o texto sempre que necessário.

## Etiquetas NFC vinculadas { #linked-nfc-tags }

Abrir **Menu principal → Configurações → Lista de tags NFC** para visualizar os dispositivos ou colmeias que o aplicativo pode identificar via NFC.

![Lista de dispositivos e colmeias vinculados via NFC](../../assets/en/app/nfc-settings/linked-nfc-tags.jpg){ .doc-screenshot }

A lista mostra o nome e o identificador de cada perfil vinculado. Tocar no bloco correspondente remove o link NFC.

!!! info "Lista de dispositivos e colmeias"
    Na lista de dispositivos e colmeias, um ícone NFC separado indica que uma etiqueta está vinculada. Um link direto para a descrição completa desta tela será adicionado após a conclusão de sua revisão.

## Ação após reconhecimento { #nfc-action }

Abrir **Menu Principal → Configurações → Ação NFC** e selecione o que o aplicativo deve abrir após reconhecer uma etiqueta NFC.

![Selecionar a ação executada após uma etiqueta NFC ser reconhecida](../../assets/en/app/nfc-settings/nfc-action-settings.jpg){ .doc-screenshot }

Ações disponíveis:

- **Colmeia aberta**;
- **Status de colmeia aberta**;
- **Evento de colmeia aberta**;
- **Evento + gravação de voz**.

A última opção abre imediatamente a criação de eventos com entrada de voz após a colmeia ser identificada.
