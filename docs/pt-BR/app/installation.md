# Instalação do aplicativo BeeApiary

## Instalação

!!! note "Permissões de aplicativos"
    Recomendamos a concessão **todas as permissões** solicitado pelo aplicativo durante a primeira inicialização. Se você negar alguns deles, alguns recursos poderão não funcionar ou funcionar incorretamente; o comportamento para todas as combinações possíveis de restrições não foi testado. Para evitar dificultar desnecessariamente a configuração e a solução de problemas, conceda todas as permissões solicitadas.

!!! warning "A permissão de SMS é necessária para GSM"
    Se você usar BeeApiary balança de colmeia e planeja receber dados via GSM, é necessária permissão para processar mensagens SMS. Sem ele, o aplicativo não consegue ler as mensagens da balança, portanto as medições não chegarão via GSM.

    Se você usar o aplicativo sem BeeApiary balanças de colmeia como um caderno independente e diário de apiário, não é necessária permissão por SMS.

1. Abra o [página do aplicativo no Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Instale e inicie o aplicativo.
3. Conceda todas as permissões solicitadas pelo aplicativo.

!!! info "Sincronização automática via Bluetooth"
    Certifique-se de que o aplicativo tenha permissões de Bluetooth e que o sistema permita que ele seja executado em segundo plano e seja ativado no horário necessário. Procedimento completo: [Configurar a sincronização via Bluetooth](../guides/configure-bluetooth-sync.md).
