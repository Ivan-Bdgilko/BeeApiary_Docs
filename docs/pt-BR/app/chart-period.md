# Período de visualização do gráfico

Toque brevemente no título da colmeia selecionada na tela inicial para abrir os gráficos.

## Duração do período

Os ícones de dia, semana e mês definem a unidade do período. Toque repetidamente no ícone relevante para selecionar 1, 2, 3 ou mais dias, semanas ou meses em sequência.

## Data de término

Toque na data e hora na parte superior do painel da colmeia selecionada e escolha a data desejada no calendário. Esta é a data final do intervalo; o aplicativo calcula a data de início a partir da duração do período selecionado.

Por exemplo, se você selecionar **4 de setembro** como a data final e **um mês** como o período, os gráficos mostram dados de **4 de agosto a 4 de setembro**.

![Selecionar a data final de um período do gráfico no BeeApiary aplicativo](../../assets/en/app/chart-period/chart-end-date-picker.jpg){ .doc-screenshot }

Você pode escolher qualquer data de término disponível, incluindo uma data de um ano atrás. Isso permite revisar medições e eventos mais antigos quando os dados correspondentes estão disponíveis no aplicativo.

Depois de fazer uma seleção, o aplicativo reconstrói o [gráficos](charts.md) para o intervalo selecionado.
