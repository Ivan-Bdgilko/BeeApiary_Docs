# Configurações do aplicativo

O **Configurações** page é o menu pai para as opções de exibição e comportamento do aplicativo. Cada item abre uma tela secundária separada.

![BeeApiary menu de configurações do aplicativo](../../../assets/en/app/settings/app-settings-menu.jpg){ .doc-screenshot }

| Item de cardápio | Função |
|---|---|
| **Ordem da tela principal** | Abre [seleção de dados e gráficos](../chart-settings.md). Essas configurações determinam quais blocos aparecem e sua ordem na tela inicial e, para valores numéricos, quais gráficos aparecem e sua ordem na tela de gráficos. |
| **ordem dos campos do estado da colmeia** | Abre o [configurações do campo de estado da colmeia](../hive-state-settings.md). |
| **Ordem da tela meteorológica** | Abre o [configurações de dados de previsão do tempo](../weather-settings.md). |
| **Configurações adicionais** | Abre [opções adicionais de comportamento do aplicativo](../additional-settings.md), incluindo exibição de eventos e operação Bluetooth. |
| **Dispositivos e colmeias** | Gerencia a lista de perfis. Adicionando [BeeApiary balanças de colmeia](../add-device.md) e [uma colmeia](../add-hive.md) são descritos separadamente; uma descrição completa desta tela ainda está sendo preparada. |
| **tipos de colmeia** | Abre o [lista de tipos de colmeias](../hive-types.md) usado no apiário. |
| **Nomes dos sensores T** | Permite atribuir nomes claros aos canais de temperatura. Uma descrição detalhada será adicionada após uma revisão separada desta tela. |
| **Lista de tags NFC** | Programas [dispositivos e colmeias vinculados via NFC](../nfc-settings.md#linked-nfc-tags). |
| **Ação NFC** | Seleciona o [ação executada após uma etiqueta NFC ser reconhecida](../nfc-settings.md#nfc-action). |
