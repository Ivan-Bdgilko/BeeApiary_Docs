# Balanças eletrônicas para colmeias BeeApiary — especificações técnicas { #_1 }

Abaixo estão as especificações do BeeApiary balanças de colmeia: faixas de medição, potência, canais de transmissão e armazenamento local de dados. Ao comparar balanças para o seu apiário, considere a configuração do dispositivo e as condições de operação, pois elas afetam a vida útil da bateria.

| Parâmetro | Valor |
|---|---|
| Peso | 0–200 kg, precisão declarada ±0,1 kg |
| Temperatura | −20 a +50 °C, resolução declarada 0,1 °C |
| Umidade, opcional | 0–100%, resolução 1% |
| Pressão, opcional | 50–950 mmHg, precisão declarada ±1 mmHg |
| Poder | 1 ou 2 18.650 células |
| Carregando | USB tipo C ou painel solar |
| Transmissão | GSM, Wi-Fi, BLE |
| Armazenamento local | microSD |
| Peso do kit | aproximadamente 0,5 kg |

A vida útil da bateria depende da configuração do dispositivo, do estado da bateria, da cobertura GSM e do número de mensagens SMS. Com a configuração recomendada são no mínimo cinco meses, mas esta duração não é garantida em todas as condições.
