# Como instalar balanças sob uma colmeia { #_1 }

Para instalar balanças sob uma colmeia, coloque a unidade principal em local abrigado e os sensores de peso em suportes firmes. As etapas abaixo cobrem a instalação e ativação inicial do BeeApiary balanças de colmeia.

1. Escolha um local protegido sob uma saliência ou cobertura de colmeia.
2. Posicione a unidade principal para minimizar a exposição à luz solar direta, chuva e neve.
3. Instale os sensores de peso em suportes firmes no mesmo plano horizontal.
4. Posicione os sensores de temperatura de acordo com suas necessidades de monitoramento.
5. Se você usar GSM, instale um micro-SIM com proteção PIN desativada.

    Orientação correta do cartão:

    ![Micro-SIM instalado corretamente](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    Insira o cartão SIM e pressione-o suavemente quase completamente no slot até ouvir um clique suave confirmando que está travado no lugar:

    ![micro-SIM bloqueado no slot](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

6. Ative ou reinicie o aparelho com a chave magnética e verifique a primeira medição.

## Ativação e reinicialização { #activation-reset }

A ativação inicial e a reinicialização seguem o mesmo procedimento: segure brevemente a chave magnética contra a marca na parte traseira da unidade principal. Você não precisa tocar em outras partes do gabinete nem abrir a unidade.

![BeeApiary chave magnética](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

![Alvo de chave magnética com marca na parte traseira da unidade principal](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

!!! danger
    Não instale o aparelho ou antena externa no ponto mais alto do apiário. Isso cria o risco de queda de raio e danos irreparáveis.

Para obter mais informações, consulte [Colocação](placement.md) e [Sensores](sensors.md).
