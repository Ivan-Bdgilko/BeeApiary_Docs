# Manutenção

- Após armazenamento prolongado, verifique a voltagem da bateria. Se estiver abaixo `3,5 В`, siga o [procedimento de recuperação](../troubleshooting/recovery-after-storage.md); caso contrário, carregue a bateria através de USB Type-C.
- Não remova a bateria, a menos que seja necessário. Após desconectá-lo, verifique a hora do dispositivo.
- Inspecione periodicamente o gabinete quanto a condensação, insetos e contaminação.
- Verifique o cartão microSD se precisar de arquivos locais e registros de serviço.
- Atualize o firmware somente através de um procedimento controlado: [Atualizando o dispositivo](../guides/update-device.md).

!!! note "Carregando"
    O dispositivo não suporta carregamento rápido, incluindo USB Power Delivery (PD). Para carregar, use uma fonte de alimentação padrão com uma porta USB Tipo A e um cabo USB Tipo A – USB Tipo C em vez de um cabo USB Tipo C – USB Tipo C.

As medições principais e a transmissão de dados podem funcionar sem um cartão microSD, mas o arquivo e os registros no cartão ficarão indisponíveis.

Antes do final da temporada, revise o [regras de uso e armazenamento no inverno](winter-use-and-storage.md).
