# Como calibrar as balanças

!!! danger
    Um novo dispositivo já está calibrado. Execute este procedimento somente após um reparo ou perda confirmada de dados de calibração.

1. Desconecte a fonte de alimentação externa.
2. Coloque os sensores e a plataforma vazia sobre uma superfície firme e nivelada.
3. Abrir **Configurações Gerais → Configurações da balança**.
4. Inicie a calibração zero e não toque na plataforma.
5. Quando tiver sucesso, selecione um peso de referência de 500, 1.000 ou 5.000 g.
6. Coloque o peso de referência na plataforma e inicie a calibração de referência.
7. Aguarde até que o peso de referência seja exibido.

Resultado: o dispositivo salvou os novos valores de calibração. Para o contexto completo, consulte [Calibração e Tara](../device/calibration-and-tare.md).
