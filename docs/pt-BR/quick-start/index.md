# Início rápido

Escolha como você deseja usar BeeApiary:

- [Configurar o sistema e GSM](full-system.md) — instale um micro-SIM e receba o primeiro SMS; adicione o aplicativo, se necessário.
- [Instale o aplicativo](app-only.md) — comece sem um dispositivo físico ou use o modo de demonstração.
- [Ponto de acesso da balança](local-wifi.md) — abra a interface web do dispositivo enquanto estiver por perto.

!!! warning "Antes de começar"
    Um novo dispositivo é fornecido calibrado. Não retire a bateria, tare ou calibre a balança sem uma necessidade específica e sem primeiro ler as respectivas instruções.
