# Instale o BeeApiary Aplicativo

O aplicativo BeeApiary também funciona sozinho, sem balança de colmeia. Assim é possível conhecer os recursos que não exigem medições automáticas.

O modo de demonstração simula a balança e mostra seus dados e telas sem equipamento físico.

1. [Instale o aplicativo BeeApiary](../app/installation.md) pelo Google Play e conceda as permissões solicitadas.
2. No menu principal, selecione **Adicionar dispositivo ou colmeia**.
3. Escolha uma opção:

    - [Adicione uma colmeia](../app/add-hive.md) para registrar diário, estado e eventos sem balança.
    - Selecione **Adicionar dados de teste** para criar uma [colmeia de demonstração com balança simulada](../app/add-device-or-hive/index.md#teste-colmeia-com-balanca-simulada).

Pronto: o aplicativo está instalado e pode funcionar sem balança ou no modo de demonstração. Uma balança real pode enviar dados por GSM, Wi-Fi direto, rede Wi-Fi do apiário ou Bluetooth. Compare as [formas de receber dados](../system/connectivity.md).
