# Instale o BeeApiary Aplicativo

O BeeApiary O aplicativo pode operar de forma independente, sem balanças de colmeia. Neste modo, você pode explorar o aplicativo e utilizar recursos que não exigem que os dados cheguem automaticamente das balanças.

Um modo de demonstração também está disponível. Ele simula BeeApiary colmeia e permite que você veja como seus dados e telas relacionadas aparecem, mesmo se você ainda não tiver balanças reais.

!!! note "Permissões de aplicativos"
    Durante o primeiro lançamento, recomendamos conceder **todas as permissões** solicitado pelo aplicativo. Se você negar alguns deles, alguns recursos poderão não funcionar ou funcionar incorretamente; o comportamento com todas as combinações possíveis de restrições não foi testado. Para evitar complicar a configuração e a solução de problemas, conceda todas as permissões solicitadas.

!!! warning "A permissão de SMS é necessária para GSM"
    O recebimento de dados via GSM não funcionará no aplicativo sem permissão para processar mensagens SMS. O aplicativo não conseguirá ler mensagens do dispositivo, portanto as medições não aparecerão.

1. Abrir [BeeApiary no Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Instale o aplicativo. Você também pode encontrá-lo no Google Play com o nome **Notas do apicultor**.
3. Inicie o aplicativo.
4. Conceda todas as permissões solicitadas pelo aplicativo.
5. Se você planeja receber dados por GSM, certifique-se de conceder permissão ao aplicativo para processar mensagens SMS.
6. Para GSM, adicione o dispositivo físico se necessário e insira o número de telefone do cartão SIM nele instalado.

Pronto: o aplicativo está instalado e pode funcionar sem balança de colmeia ou em modo de demonstração. Dados reais BeeApiary As balanças de colmeia podem acessar o aplicativo através de GSM, uma conexão Wi-Fi direta ao dispositivo, a rede Wi-Fi do apiário ou Bluetooth. Compare o [métodos para receber dados no aplicativo](../system/connectivity.md) para escolher o canal necessário.

Para obter mais informações, consulte [Instalando o aplicativo](../app/installation.md).
