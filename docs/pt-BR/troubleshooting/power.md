# Problemas de energia

!!! note "Carregando"
    O dispositivo não suporta carregamento rápido, incluindo USB Power Delivery (PD). Para testar, use uma fonte de alimentação padrão com uma porta USB Tipo A e um cabo USB Tipo A para USB Tipo C. Um cabo USB Type-C para USB Type-C não é recomendado.

1. Após armazenamento prolongado, verifique a voltagem da bateria. Se estiver abaixo `3,5 В`, siga o [procedimento de recuperação após armazenamento](recovery-after-storage.md).
2. Em outros casos, conecte uma fonte de alimentação padrão funcional à porta USB Type-C e deixe a bateria carregar.
3. Certifique-se de que a bateria instalada no BeeApiary A balança de colmeia destina-se à configuração desse modelo específico. Os modelos que utilizam células 18650 devem ter pelo menos uma dessas células instalada.
4. Se a bateria tiver sido substituída, verifique a polaridade em relação às marcações no suporte.
5. Após uma descarga crítica, deixe a carga da bateria se recuperar; o dispositivo pode retomar a operação normal durante o próximo ciclo.
6. Após a recuperação, verifique a hora e sincronize-a, se necessário.

!!! danger
    Não tente alimentar o dispositivo apenas através de USB externo sem uma célula 18650. A polaridade incorreta da bateria pode danificar permanentemente o dispositivo.

Para obter detalhes, consulte [Poder](../device/power.md).
