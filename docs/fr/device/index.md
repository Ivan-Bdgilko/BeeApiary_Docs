# Balances BeeApiary — balances électroniques pour ruches { #beeapiary }

BeeApiary Les balances pour ruches sont des balances électroniques pour ruches conçues pour un fonctionnement en extérieur. Ils prennent des mesures, les stockent sur microSD et les envoient au propriétaire via les canaux de communication disponibles. Avec les capteurs et l'application, la balance forme un BeeApiary ruche intelligente pour une surveillance locale ou à distance.

Ces appareils sont également connus sous le nom de balances pour abeilles.

Principaux composants et options :

- mesure du poids jusqu'à 200 kg;
- deux capteurs de température ;
- capteurs d'humidité et de pression en option ;
- capteur de mouvement et écran OLED en option ;
- GSM, Wi-Fi et Bluetooth ;
- alimentation à partir d’une ou deux cellules 18650 ; selon le modèle et la configuration de la carte, l'appareil peut être fourni avec un autre type de batterie.

L'appareil est conçu pour une utilisation en extérieur et possède un indice de protection IP65.
