# Balances électroniques pour ruches BeeApiary — caractéristiques techniques { #_1 }

Vous trouverez ci-dessous les spécifications du BeeApiary balances pour ruches : plages de mesure, puissance, canaux de transmission et stockage local des données. Lorsque vous comparez les balances pour votre rucher, tenez compte de la configuration de l'appareil et des conditions de fonctionnement, car elles affectent la durée de vie de la batterie.

| Paramètre | Valeur |
|---|---|
| Poids | 0–200 kg, précision déclarée ±0,1 kg |
| Température | −20 à +50 °C, résolution indiquée 0,1 °C |
| Humidité, en option | 0 à 100 %, résolution 1 % |
| Pression, en option | 50–950 mmHg, précision déclarée ±1 mmHg |
| Puissance | 1 ou 2 cellules 18650 |
| Chargement | USB Type-C ou panneau solaire |
| Transmission | GSM, Wi-Fi, BLE |
| Stockage local | microSD |
| Poids du kit | environ 0,5kg |

La durée de vie de la batterie dépend de la configuration de l'appareil, de l'état de la batterie, de la couverture GSM et du nombre de messages SMS. Avec la configuration recommandée, elle est d'au moins cinq mois, mais cette durée n'est pas garantie dans toutes les conditions.
