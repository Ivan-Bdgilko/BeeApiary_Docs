# Dépannage

Sélectionnez le symptôme que vous pouvez observer :

- [Aucun message SMS n'est reçu](no-sms.md)
- [Le poids est incorrect ou instable](incorrect-weight.md)
- [Impossible de se connecter au Wi-Fi](wifi-connection.md)

Ne démarrez pas l'étalonnage, ne retirez pas la batterie et ne modifiez pas les champs XML de service comme première étape de dépannage.
