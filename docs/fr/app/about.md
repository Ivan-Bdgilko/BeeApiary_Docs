# À propos de l'application

Le **À propos de l'application** La page donne un bref aperçu de BeeApiary, des liens utiles et des détails sur la version installée.

![La page À propos dans BeeApiary](../../assets/en/app/about/about-app-screen.png){ .doc-screenshot }

La page donne accès à :

- **YouTube** - des guides vidéo pour la configuration et l'utilisation ;
- **Manuel d'utilisation** - le BeeApiary documentation textuelle ;
- **Courriel** - contact avec le support par email ;
- un bref aperçu des fonctionnalités de l'application et du journal du rucher.

## Version de l'application

L'identifiant de version et la date de build sont affichés en bas de la page.

![Identifiant de la version de l'application et date de build](../../assets/common/app/about/app-version-build.png){ .doc-screenshot }

Ces informations vous aident à vérifier si l'application est à jour et à identifier la version exacte lorsque vous contactez l'assistance.
