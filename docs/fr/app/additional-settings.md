# Paramètres d'application supplémentaires

Des paramètres supplémentaires contrôlent le filtrage des données, l'apparence de l'application, l'affichage des événements et la synchronisation locale via Bluetooth.

![Paramètres supplémentaires dans le BeeApiary Application Android](../../assets/en/app/additional-settings/app-additional-settings.jpg){ .doc-screenshot }

| Paramètre | Fonction |
|---|---|
| **Filtrer les pointes élevées** | Supprime les pointes de mesure occasionnelles et pointues de l'écran. |
| **Afficher les événements** | Affiche les événements enregistrés pour la ruche. |
| **Événements au-dessus des graphiques** | Affecte uniquement la vue graphique et contrôle l'ordre des couches : les événements sont dessinés sur les graphiques ou les graphiques sont dessinés sur les événements, en fonction de l'état du commutateur. |
| **Mode nuit permanent** | Maintient le thème sombre de l'application activé à tout moment. |
| **Afficher les conseils** | Affiche les panneaux d'aide sur les écrans d'application. |
| **Rechercher des appareils BLE** | Permet à l'application de trouver à proximité BeeApiary balances pour ruches et recevez les données disponibles via Bluetooth. Pour un fonctionnement correct, [**BLE info**](../device/additional-settings.md) doit être activé sur chaque balance que vous souhaitez synchroniser. |
| **Histoire du BLE** | Reçoit un historique de mesure plus long ainsi que les données actuelles via Bluetooth, jusqu'à une semaine dans l'historique disponible sur l'appareil. Ceci est utile si vous visitez le rucher environ une fois par semaine. |

Pour les deux derniers réglages, suivez la procédure complète [Configurer la synchronisation Bluetooth](../guides/configure-bluetooth-sync.md) guider.

!!! note "Ne confondez pas les deux écrans"
    Cette page décrit les paramètres de l'application Android. Options matérielles et canaux de communication du BeeApiary les balances pour ruches sont décrites sous [Paramètres supplémentaires de l'appareil](../device/additional-settings.md).
