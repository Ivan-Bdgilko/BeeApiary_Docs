# Installation de l’application BeeApiary

## Mise en place

!!! note "Autorisations des applications"
    Nous recommandons d'accorder **toutes les autorisations** demandé par l'application lors du premier lancement. Si vous en refusez certaines, certaines fonctionnalités risquent de ne pas fonctionner ou de fonctionner incorrectement ; le comportement pour chaque combinaison possible de restrictions n’a pas été testé. Pour éviter de rendre la configuration et le dépannage inutilement difficiles, accordez toutes les autorisations demandées.

!!! warning "L'autorisation SMS est requise pour le GSM"
    Si vous utilisez BeeApiary balances pour ruches et prévoyez de recevoir des données via GSM, une autorisation de traitement des messages SMS est requise. Sans cela, l'application ne peut pas lire les messages de la balance, les mesures n'arriveront donc pas via GSM.

    Si vous utilisez l'application sans BeeApiary balances de ruche en tant que carnet autonome et journal du rucher, l'autorisation SMS n'est pas requise.

1. Ouvrez le [page de l'application sur Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Installez et lancez l'application.
3. Accordez toutes les autorisations demandées par l'application.

!!! info "Synchronisation automatique via Bluetooth"
    Assurez-vous que l'application dispose des autorisations Bluetooth et que le système lui permet de s'exécuter en arrière-plan et de se réveiller à l'heure requise. Procédure complète : [Configurer la synchronisation via Bluetooth](../guides/configure-bluetooth-sync.md).

## Prochaines étapes

Après l'installation, choisissez le scénario dont vous avez besoin :

- [Ajouter BeeApiary balances pour ruches](add-device.md) pour recevoir automatiquement les mesures.
- [Ajouter une ruche](add-hive.md) pour conserver sa description, son état, ses notes et ses événements même sans appareil physique.

APK antérieurs dans le [Dépôt Android_Apk](https://github.com/Ivan-Bdgilko/Android_Apk) sont obsolètes. Utilisez Google Play pour l'installation actuelle.
