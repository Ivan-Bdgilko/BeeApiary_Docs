# Outils supplémentaires

Le **Outils supplémentaires** Le sous-menu contient des commandes pour sauvegarder les données et les diagnostics de service.

![Menu Outils supplémentaires dans le BeeApiary application](../../assets/en/app/additional-tools/additional-tools-menu.png){ .doc-screenshot }

| Commande | Fonction |
|---|---|
| **Enregistrer les données (copie de sauvegarde)** | Crée une copie de sauvegarde de la base de données de l'application. |
| **Restaurer les données** | Restaure les données de l'application à partir d'une copie de sauvegarde précédemment créée. |
| **Enregistrer le fichier journal** | Enregistre un fichier journal de service que vous pouvez envoyer au support pour les diagnostics. |

!!! warning "Conserver une copie de sauvegarde à jour"
    Avant de restaurer, assurez-vous d'avoir sélectionné la copie requise des données. Enregistrez la sauvegarde actuelle séparément si vous devez la restaurer ultérieurement.
