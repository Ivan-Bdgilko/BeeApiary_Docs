# Types de ruches

Le **types de ruches** L'écran vous permet d'adapter la liste des types de corps de ruche à ceux utilisés dans votre rucher. L'application comprend plusieurs types d'échantillons, mais la liste initiale n'est pas destinée à couvrir tous les modèles de ruches.

La plupart des ruchers utilisent entre un et cinq types de corps de ruche, la liste initiale fournit donc une capacité supplémentaire pour une utilisation typique. Vous pouvez librement modifier les types existants ou étendre la liste pour correspondre à votre rucher.

1. Ouvert **Menu principal → Paramètres → types de ruches**.
2. Recherchez le type requis dans la liste.
3. Appuyez sur sa vignette pour configurer la façon dont elle est utilisée dans l'application.

![Liste des types de ruches dans le BeeApiary application](../../assets/en/app/hive-types/hive-types-list.jpg){ .doc-screenshot }

Ce paramètre appartient aux descriptions de ruche dans l'application et ne modifie pas la configuration matérielle du BeeApiary balances pour ruches.
