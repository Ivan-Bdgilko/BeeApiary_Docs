# Paramètres de l'application

Le **Paramètres** La page est le menu parent des options d'affichage et de comportement de l'application. Chaque élément ouvre un écran enfant distinct.

![BeeApiary menu des paramètres de l'application](../../../assets/en/app/settings/app-settings-menu.jpg){ .doc-screenshot }

| Élément de menu | Fonction |
|---|---|
| **Ordre de l'écran principal** | Ouvre [sélection de données et de graphiques](../chart-settings.md). Ces paramètres déterminent quelles vignettes apparaissent et leur ordre sur l'écran d'accueil et, pour les valeurs numériques, quels graphiques apparaissent et leur ordre sur l'écran des graphiques. |
| **ordre des champs d'état de la ruche** | Ouvre le [Paramètres du champ d'état de la ruche](../hive-state-settings.md). |
| **Ordre de l'écran météo** | Ouvre le [paramètres des données de prévisions météorologiques](../weather-settings.md). |
| **Paramètres supplémentaires** | Ouvre [options de comportement d'application supplémentaires](../additional-settings.md), y compris l'affichage des événements et le fonctionnement Bluetooth. |
| **Appareils et ruches** | Gère la liste des profils. Ajout [BeeApiary balances pour ruches](../add-device.md) et [une ruche](../add-hive.md) sont décrits séparément ; une description complète de cet écran est toujours en cours de préparation. |
| **types de ruches** | Ouvre le [liste des types de ruches](../hive-types.md) utilisé au rucher. |
| **Noms des capteurs T** | Vous permet d'attribuer des noms clairs aux canaux de température. Une description détaillée sera ajoutée après un examen séparé de cet écran. |
| **Liste des balises NFC** | Spectacles [appareils et ruches reliés via NFC](../nfc-settings.md#linked-nfc-tags). |
| **Action NFC** | Sélectionne le [action effectuée après la reconnaissance d'une balise NFC](../nfc-settings.md#nfc-action). |
