# Ajoutez une balance ou une ruche

Le **Appareils et ruches** l'écran vous permet de :

- ajouter du physique BeeApiary balances de pesée pour ruches selon le profil d'une ruche ;
- créer un profil de ruche sans aucun équipement ;
- démarrez une ruche de démonstration avec des balances et des données de test pour explorer l'application.

![Options d'ajout BeeApiary une balance, une ruche ou des données de test](../../../assets/en/app/add-device-or-hive/add-scales-hive-or-test-data.jpg){ .doc-screenshot }

## BeeApiary Balances pour ruches

Le **Ajouter un appareil** Le bouton crée un profil de ruche lié au physique BeeApiary balances pour ruches. Ce profil peut recevoir automatiquement le poids, la température et d'autres lectures disponibles.

Continuez avec [Ajouter BeeApiary Balances pour ruches](../add-device.md). Vous pouvez comparer le GSM, une connexion Wi-Fi directe, le réseau Wi-Fi du rucher et le Bluetooth sous [Réception de données dans l'application](../../system/connectivity.md).

## ruche Sans balance

Le **Ajouter une ruche** Le bouton crée un profil séparé sans balance physique. Vous pouvez l'utiliser pour tenir un journal, décrire les [statut de la ruche](../hive-state.md), ajoutez des notes et enregistrez [événements](../events-and-notes.md).

Continuez avec [Ajouter une ruche](../add-hive.md).

## Testez la ruche avec des balances simulées

Le **Ajouter des données de test** Le bouton crée une ruche de démonstration avec des balances de ruche simulées. L'application génère des données similaires aux lectures réelles, vous permettant d'explorer l'écran d'accueil, les graphiques, l'état de la ruche et les événements et de travailler avec eux comme vous le feriez avec un profil lié à de véritables balances intelligentes.

Les valeurs de test servent uniquement à présenter l’application et ne sont pas des mesures réelles.
