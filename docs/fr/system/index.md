# Comment fonctionne le système

Avec les capteurs et l'application, BeeApiary les balances de ruche forment un BeeApiary ruche intelligente. La balance mesure et stocke les données localement, tandis que le BeeApiary L'application Android la reçoit, la stocke et la présente à l'utilisateur.

Les données peuvent atteindre l'application via GSM, une connexion Wi-Fi directe à l'appareil, le routage via le réseau Wi-Fi du rucher ou Bluetooth. Le système ne nécessite pas de serveur externe pour son fonctionnement principal et le relais en ligne ne stocke pas de données.
