# Comment mettre à jour l’application BeeApiary

1. Ouvert [BeeApiary sur Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Si une mise à jour est disponible, appuyez sur **Mise à jour**.
3. Après avoir lancé l'application, vérifiez toutes les autorisations requises pour qu'elle fonctionne et accordez toutes les autorisations manquantes. Assurez-vous que les appareils que vous avez ajoutés sont toujours dans la liste.

Fichiers APK obsolètes dans [Android_Apk](https://github.com/Ivan-Bdgilko/Android_Apk) ne peut contenir que des versions plus anciennes. Google Play est la principale source d'installation.
