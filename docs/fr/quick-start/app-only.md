# Installez le BeeApiary Application

Le BeeApiary L'application peut fonctionner indépendamment sans balance de ruche. Dans ce mode, vous pouvez explorer l'application et utiliser des fonctionnalités qui ne nécessitent pas que les données arrivent automatiquement de la balance.

Un mode démonstration est également disponible. Il simule BeeApiary balances de ruche et vous permet de voir comment leurs données et les écrans associés apparaissent même si vous ne disposez pas encore de véritables balances.

!!! note "Autorisations des applications"
    Lors du premier lancement, nous recommandons d'accorder **toutes les autorisations** demandé par l'application. Si vous en refusez certaines, certaines fonctionnalités risquent de ne pas fonctionner ou de fonctionner incorrectement ; le comportement avec toutes les combinaisons possibles de restrictions n’a pas été testé. Pour éviter de compliquer la configuration et le dépannage, accordez toutes les autorisations demandées.

!!! warning "L'autorisation SMS est requise pour le GSM"
    La réception de données via GSM ne fonctionnera pas du tout dans l'application sans l'autorisation de traiter les messages SMS. L'application ne pourra pas lire les messages de l'appareil, les mesures n'apparaîtront donc pas.

1. Ouvert [BeeApiary sur Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Installez l'application. Vous pouvez également le trouver sur Google Play sous le nom **Notes de l'apiculteur**.
3. Lancez l'application.
4. Accordez toutes les autorisations demandées par l'application.
5. Si vous prévoyez de recevoir des données via GSM, assurez-vous d'accorder à l'application l'autorisation de traiter les messages SMS.
6. Pour le GSM, ajoutez l'appareil physique si nécessaire et saisissez le numéro de téléphone de la carte SIM qui y est installée.

C'est fait : l'application est installée et peut fonctionner sans balance pour ruches ou en mode démonstration. Données provenant du réel BeeApiary Les balances pour ruches peuvent accéder à l'application via GSM, une connexion Wi-Fi directe à l'appareil, le réseau Wi-Fi du rucher ou Bluetooth. Comparez les [méthodes de réception de données dans l'application](../system/connectivity.md) pour choisir le canal souhaité.

Pour plus d'informations, voir [Installation de l'application](../app/installation.md).
