# Connexion à l'appareil via GSM

!!! warning
    Utilisez une carte micro-SIM. Désactivez au préalable la protection par code PIN de la carte SIM.

    ![Comparaison des formats de cartes SIM](../../assets/en/quick-start/gsm/micro-sim-format-comparison.png){ .doc-photo }

1. [Installez le BeeApiary application](app-only.md) si nécessaire. Il n'est pas nécessaire de recevoir des messages SMS ordinaires. Si l'application doit traiter automatiquement les données de mesure des messages SMS, l'autorisation SMS est obligatoire.
2. Ouvrez le couvercle de l'unité de collecte de données.

    ![Cellule de collecte de données ouvertes](../../assets/common/device/installation/open-data-collection-unit.png){ .doc-photo }

3. Insérez la micro-SIM dans l'emplacement approprié.

    Position correcte de la carte :

    ![Micro-SIM correctement insérée](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    Insérez la carte SIM et appuyez doucement jusqu'à ce qu'elle soit presque entièrement enfoncée dans l'emplacement et que vous entendiez un léger clic confirmant son verrouillage :

    ![micro-SIM verrouillée dans l'emplacement](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

4. Activez ou redémarrez l'appareil de la même manière : maintenez brièvement la clé magnétique contre le marquage au dos de l'unité principale.

    ![BeeApiary clé magnétique](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

    ![Cible de clé magnétique de marque sur l'unité principale](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

5. Attendez environ une minute.
6. Confirmez que le premier SMS arrive au numéro préconfiguré.

Terminé : l'appareil a été activé ou redémarré et peut envoyer des mesures via GSM.

Si le numéro du propriétaire n'a pas encore été configuré, [configurer le numéro via le réseau Wi-Fi local](../guides/configure-gsm.md).
