# Démarrage rapide

Choisissez comment vous souhaitez utiliser BeeApiary:

- [Configurer le système](full-system.md) — installer une micro-SIM et recevoir les premiers SMS ; ajoutez l'application si nécessaire.
- [Installez l'application](app-only.md) — démarrez sans appareil physique ou utilisez le mode démo.
- [Connectez-vous à l'appareil via GSM](gsm.md) — recevoir des mesures par SMS.
- [Réseau Wi-Fi local](local-wifi.md) - ouvrez l'interface Web de l'appareil lorsque vous êtes à proximité.

!!! warning "Avant de commencer"
    Un nouvel appareil est fourni calibré. Ne retirez pas la batterie, ne tarez pas et ne calibrez pas la balance sans besoin spécifique et sans avoir lu au préalable les instructions correspondantes.
