# Cihaza GSM Üzerinden Bağlanma

!!! warning
    Mikro SIM kart kullanın. SIM kart PIN korumasını önceden devre dışı bırakın.

    ![SIM kart formatlarının karşılaştırılması](../../assets/en/quick-start/gsm/micro-sim-format-comparison.png){ .doc-photo }

1. [Şunu yükleyin: BeeApiary uygulama](app-only.md) gerekirse. Sıradan SMS mesajları almanıza gerek yoktur. Uygulamanın SMS mesajlarındaki ölçüm verilerini otomatik olarak işlemesi gerekiyorsa SMS izni zorunludur.
2. Veri toplama ünitesinin kapağını açın.

    ![Açık veri toplama birimi](../../assets/common/device/installation/open-data-collection-unit.png){ .doc-photo }

3. Mikro SIM'i uygun yuvaya takın.

    Doğru kart konumu:

    ![Doğru şekilde yerleştirilmiş mikro SIM](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    SIM kartı takın ve yuvaya neredeyse tamamen girinceye kadar hafifçe bastırın; yerine kilitlendiğini onaylayan hafif bir tıklama duyuncaya kadar:

    ![mikro SIM yuvaya kilitlendi](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

4. Cihazı aynı şekilde etkinleştirin veya yeniden başlatın: Manyetik anahtarı ana ünitenin arkasındaki marka işaretine kısa süreliğine tutun.

    ![BeeApiary manyetik anahtar](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

    ![Ana ünitede markalı manyetik anahtarlı hedef](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

5. Yaklaşık bir dakika bekleyin.
6. İlk SMS'in önceden yapılandırılmış numaraya ulaştığını doğrulayın.

Bitti: Cihaz etkinleştirildi veya yeniden başlatıldı ve ölçümleri GSM üzerinden gönderebiliyor.

Sahibin numarası henüz yapılandırılmamışsa, [numarayı yerel Wi-Fi ağı üzerinden yapılandırın](../guides/configure-gsm.md).
