# Tartım Terazisinin Darası Nasıl Alınır?

Dara alma, platformun veya başka bir kalıcı yapının ağırlığını ölçümlerin dışında bırakır.

1. Web arayüzüne bağlanın BeeApiary arı kovanı tartı terazileri.
2. Açık **Genel Ayarlar → Tartı Ayarları**.
3. Dara ağırlığını biliyorsanız gram cinsinden girin ve **Dara Ağırlığını Ayarla**.
4. Alternatif olarak sensörler üzerinde gerekli yapıyı bırakıp mevcut değeri sıfır kabul eden seçeneği seçin.
5. İşlem tamamlandığında okumayı kontrol edin.

Sonuç: Cihaz belirtilen dara değerini sonraki ölçümlerden çıkarır. Dara alma kalibrasyon değildir.
