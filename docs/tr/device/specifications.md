# BeeApiary elektronik kovan tartıları — teknik özellikler { #_1 }

Aşağıda özellikleri yer almaktadır BeeApiary arı kovanı tartı terazileri: ölçüm aralıkları, güç, iletim kanalları ve yerel veri depolama. Arılığınız için tartım terazilerini karşılaştırırken, pil ömrünü etkilediği için cihaz yapılandırmasını ve çalışma koşullarını göz önünde bulundurun.

| Parametre | Değer |
|---|---|
| Ağırlık | 0–200 kg, belirtilen doğruluk ±0,1 kg |
| Sıcaklık | −20 ila +50 °C, belirtilen çözünürlük 0,1 °C |
| Nem, isteğe bağlı | %0–100, çözünürlük %1 |
| Basınç, isteğe bağlı | 50–950 mmHg, belirtilen doğruluk ±1 mmHg |
| Güç | 1 veya 2 18650 hücre |
| Şarj etme | USB Tip-C veya güneş paneli |
| İletim | GSM, Wi-Fi, BLE |
| Yerel depolama | microSD |
| Kit ağırlığı | yaklaşık 0,5 kg |

Pil ömrü, cihazın yapılandırmasına, pil durumuna, GSM kapsama alanına ve SMS mesajı sayısına bağlıdır. Önerilen konfigürasyonda bu süre en az beş aydır ancak bu süre her koşulda garanti edilmez.
