# Inicio rápido

Elige cómo quieres usar BeeApiary:

- [Configurar el sistema](full-system.md) — instalar una micro-SIM y recibir el primer SMS; agregue la aplicación si es necesario.
- [Instalar la aplicación](app-only.md) — comience sin un dispositivo físico o use el modo de demostración.
- [Conéctese al dispositivo a través de GSM](gsm.md) — recibir mediciones a través de SMS.
- [Red wifi local](local-wifi.md) — abre la interfaz web del dispositivo mientras estás cerca.

!!! warning "Antes de empezar"
    Se suministra un dispositivo nuevo calibrado. No retire la batería, tara o calibre la báscula sin una necesidad específica y sin leer previamente las instrucciones pertinentes.
