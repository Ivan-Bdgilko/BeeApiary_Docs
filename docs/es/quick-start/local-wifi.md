# Conexión rápida a una red Wi-Fi local

1. [Activar o reiniciar el dispositivo](../device/installation.md#activation-reset): mantenga brevemente la llave magnética contra la marca en la parte posterior de la unidad principal.
2. En un minuto, abra la lista de redes Wi-Fi en su teléfono, tableta o computadora portátil.
3. Conéctate a `apiary_net` usando la contraseña inicial `apiary_wifi`.
4. Abierto [http://192.168.4.1](http://192.168.4.1).
5. Asegúrese de que aparezca la página de inicio del dispositivo.
6. Cuando termine de configurar el dispositivo, desconéctese de `apiary_net`.

Listo: la interfaz web del dispositivo está disponible sin acceso a Internet.

!!! warning "Seguridad"
    Cambie la contraseña inicial de Wi-Fi después de la primera verificación. Para obtener más información, consulte [Red Wi-Fi local](../system/local-wifi.md).
