# Cómo calibrar las básculas

!!! danger
    Ya hay un nuevo dispositivo calibrado. Realice este procedimiento sólo después de una reparación o pérdida confirmada de datos de calibración.

1. Desconecte la fuente de alimentación externa.
2. Coloque los sensores y la plataforma vacía sobre una superficie firme y nivelada.
3. Abierto **Ajustes generales → Ajustes de báscula**.
4. Inicie la calibración a cero y no toque la plataforma.
5. Cuando lo consiga, seleccione un peso de referencia de 500, 1000 o 5000 g.
6. Coloque el peso de referencia en la plataforma e inicie la calibración de referencia.
7. Espere hasta que se muestre el peso de referencia.

Resultado: el dispositivo ha guardado los nuevos valores de calibración. Para el contexto completo, ver [Calibración y Tara](../device/calibration-and-tare.md).
