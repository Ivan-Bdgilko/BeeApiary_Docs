# Cómo tarar la balanza

La tara excluye de las mediciones el peso de la plataforma u otra estructura permanente.

1. Conéctese a la interfaz web del BeeApiary balanzas de colmena.
2. Abierto **Ajustes generales → Ajustes de báscula**.
3. Si conoce el peso de tara, ingréselo en gramos y seleccione **Establecer peso de tara**.
4. Alternativamente, deje la estructura requerida en los sensores y elija la opción que acepte el valor actual como cero.
5. Verifique la lectura cuando se complete la operación.

Resultado: el dispositivo resta la tara especificada de las mediciones posteriores. Tarar no es calibrar.
