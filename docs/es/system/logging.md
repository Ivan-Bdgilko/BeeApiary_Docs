# Registros

El BeeApiary Las básculas para colmenas proporcionan tres tipos diferentes de datos:

1. un archivo de mediciones CSV para el usuario;
2. un registro de servicio del dispositivo en la tarjeta microSD;
3. un registro de ingeniería en tiempo real a través de la interfaz web.

Los registros de servicio están destinados al diagnóstico, no a la visualización de rutina. Están disponibles en la tarjeta microSD; la interfaz web también proporciona las direcciones de servicio `/log` y `/tracecontrol`.

!!! warning
    No cambie el nivel de registro de ingeniería a menos que sea necesario o recomendado por el desarrollador. Utilice el [archivo de datos](data-storage.md) para analizar mediciones.
