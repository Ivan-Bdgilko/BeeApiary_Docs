# El peso es incorrecto o inestable

1. Compruebe cómo está instalado el sistema de pesaje:

    - en una configuración de cuatro sensores, cada sensor debe descansar sobre un soporte plano y firme, con todos los soportes en el mismo plano;
    - Una plataforma en forma de cruz con un sensor central también debe tener un soporte firme y estable y no debe balancearse.

    No es necesaria una nivelación precisa con un nivel de burbuja. Una ligera inclinación es aceptable, pero una instalación inestable, el balanceo o el desplazamiento de los soportes pueden provocar errores y lecturas inestables.

2. Asegúrese de que la colmena no se balancee y que los sensores no estén sumergidos en agua.
3. Elimine cualquier contacto entre la plataforma y otros objetos.
4. Desconecte la alimentación externa: una fuente de alimentación sin filtrar puede reducir la calidad de la medición.
5. Consultar la tara configurada.
6. Repita la medición sin cambiar la calibración.

!!! danger
    No calibre un dispositivo nuevo debido a un único resultado sospechoso. Utilice la calibración después de una reparación o pérdida de datos confirmada: [Calibrar las balanzas](../guides/calibrate-scales.md).
