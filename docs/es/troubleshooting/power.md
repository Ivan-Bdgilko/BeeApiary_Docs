# Problemas de energía

!!! note "Cargando"
    El dispositivo no admite carga rápida, incluida la entrega de energía USB (PD). Para realizar pruebas, utilice una fuente de alimentación estándar con un puerto USB tipo A y un cable USB tipo A a USB tipo C. No se recomienda un cable USB tipo C a USB tipo C.

1. Después de un almacenamiento prolongado, verifique el voltaje de la batería. si esta debajo `3,5 В`, sigue el [procedimiento de recuperación después del almacenamiento](recovery-after-storage.md).
2. En otros casos, conecte una fuente de alimentación estándar que funcione al puerto USB tipo C y deje que la batería se cargue.
3. Asegúrese de que la batería instalada en el BeeApiary La báscula para colmenas está diseñada para la configuración de ese modelo en particular. Los modelos que utilizan celdas 18650 deben tener al menos una de esas celdas instalada.
4. Si se ha reemplazado la batería, verifique su polaridad con las marcas en el soporte.
5. Después de una descarga crítica, permita que se recupere la carga de la batería; el dispositivo puede reanudar su funcionamiento normal durante el siguiente ciclo.
6. Después de la recuperación, verifique la hora y sincronícela si es necesario.

!!! danger
    No intente alimentar el dispositivo únicamente desde un USB externo sin una celda 18650. La polaridad incorrecta de la batería puede dañar permanentemente el dispositivo.

Para más detalles, consulte [poder](../device/power.md).
