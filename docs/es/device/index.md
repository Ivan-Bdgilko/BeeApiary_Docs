# Balanzas BeeApiary — balanzas electrónicas para colmenas { #beeapiary }

BeeApiary Las básculas para colmenas son básculas electrónicas colmena diseñadas para funcionar en exteriores. Toman medidas, las almacenan en microSD y las envían al propietario a través de los canales de comunicación disponibles. Junto con los sensores y la aplicación, la báscula forma un BeeApiary Colmena inteligente para monitoreo local o remoto.

![Características principales de las balanzas para colmenas BeeApiary](../../assets/es/device/overview/beehive-scales-features.png){ .doc-screenshot }

Estos dispositivos también se conocen como básculas para abejas.

Componentes principales y opciones:

- medición de peso hasta 200–300 kg (según la configuración);
- dos sensores de temperatura;
- sensores opcionales de humedad y presión;
- sensor de movimiento opcional y pantalla OLED;
- GSM, Wi-Fi y Bluetooth;
- energía de una o dos celdas 18650; Dependiendo del modelo y configuración de la placa, el dispositivo podrá suministrarse con otro tipo de batería.

El dispositivo está diseñado para uso en exteriores y tiene un grado de protección IP65.
