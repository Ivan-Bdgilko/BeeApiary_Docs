# Balanzas electrónicas para colmenas BeeApiary — especificaciones { #_1 }

A continuación se muestran las especificaciones del BeeApiary Balanzas de colmena: rangos de medición, potencia, canales de transmisión y almacenamiento local de datos. Al comparar básculas para su colmenar, tenga en cuenta la configuración del dispositivo y las condiciones de funcionamiento, ya que afectan la duración de la batería.

| Parámetro | Valor |
|---|---|
| Peso | 0–200 kg, precisión indicada ±0,1 kg |
| Temperatura | −20 a +50 °C, resolución indicada 0,1 °C |
| Humedad, opcional | 0–100%, resolución 1% |
| Presión, opcional | 50–950 mmHg, precisión indicada ±1 mmHg |
| poder | 1 o 2 celdas 18650 |
| Cargando | USB tipo C o panel solar |
| Transmisión | GSM, Wi-Fi, BLE |
| Almacenamiento local | microSD |
| Peso del kit | aproximadamente 0,5 kilogramos |

La duración de la batería depende de la configuración del dispositivo, el estado de la batería, la cobertura GSM y la cantidad de mensajes SMS. Con la configuración recomendada es de al menos cinco meses, pero esta duración no está garantizada en todas las condiciones.
