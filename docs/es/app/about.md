# Acerca de la aplicación

El **Acerca de la aplicación** La página proporciona una breve descripción general de BeeApiary, enlaces útiles y detalles sobre la versión instalada.

![La página Acerca de en BeeApiary](../../assets/en/app/about/about-app-screen.png){ .doc-screenshot }

La página proporciona acceso a:

- **youtube** - guías en vídeo para la instalación y el uso;
- **manual de usuario** - el BeeApiary documentación de texto;
- **Correo electrónico** - contactar con soporte por correo electrónico;
- una breve descripción general de las características de la aplicación y el diario del apiario.

## Versión de la aplicación

El identificador de versión y la fecha de compilación se muestran en la parte inferior de la página.

![Identificador de versión de la aplicación y fecha de compilación](../../assets/common/app/about/app-version-build.png){ .doc-screenshot }

Esta información le ayuda a comprobar si la aplicación está actualizada e identificar la versión exacta cuando se comunique con el soporte.
