# Agregar una colmena

Cree un perfil de colmena sin básculas físicas para llevar su diario, registrar su estado, agregar notas y guardar eventos planificados y completados. Este escenario no requiere básculas para colmenas, una tarjeta SIM ni permiso para procesar SMS.

1. Abierto **Menú principal → Agregar dispositivo o colmena**.
2. en el **Dispositivos y colmenas.** pantalla, toque **Agregar colmena**.
3. Ingresa un nombre que te ayudará a encontrar esta colmena fácilmente.
4. Toque **Insertar**.

    ![Formulario para añadir un perfil de colmena sin báscula de colmena](../../assets/en/app/add-hive/add-hive-form.jpg){ .doc-screenshot }

Después de guardar, el perfil aparece en la lista compartida de dispositivos y colmenas. uso [estado de la colmena](hive-state.md) y [Eventos y notas](events-and-notes.md) para construir su historia a lo largo del tiempo.
