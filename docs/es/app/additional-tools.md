# Herramientas adicionales

El **Herramientas adicionales** El submenú contiene comandos para realizar copias de seguridad de datos y diagnósticos de servicio.

![Menú de herramientas adicionales en el BeeApiary aplicación](../../assets/en/app/additional-tools/additional-tools-menu.png){ .doc-screenshot }

| Comando | Función |
|---|---|
| **Guardar datos (copia de seguridad)** | Crea una copia de seguridad de la base de datos de la aplicación. |
| **Restaurar datos** | Restaura los datos de la aplicación a partir de una copia de seguridad creada previamente. |
| **Guardar archivo de registro** | Guarda un archivo de registro de servicio que puede enviar al soporte para realizar diagnósticos. |

!!! warning "Mantenga una copia de seguridad actualizada"
    Antes de restaurar, asegúrese de haber seleccionado la copia requerida de los datos. Guarde la copia de seguridad actual por separado si es posible que necesite restaurarla más adelante.
