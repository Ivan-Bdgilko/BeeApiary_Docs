# Etiquetas y acciones NFC

La configuración de NFC consta de dos pantallas relacionadas: la lista de etiquetas vinculadas y la acción que realiza la aplicación después de reconocer una colmena.

## ¿Qué es una etiqueta NFC?

Una etiqueta NFC es un pequeño identificador electrónico. Puede ser un llavero, una moneda, una pegatina, una tarjeta NFC estándar o una tarjeta colmena especial. Coloque la etiqueta en la colmena en un lugar conveniente para escanear, como debajo del techo o en una pared.

Cuando sostiene un teléfono habilitado para NFC cerca de la etiqueta, la aplicación identifica rápidamente la colmena específica y realiza la acción seleccionada: abre los detalles, el estado o los eventos de la colmena, o inmediatamente comienza a crear un evento mediante la entrada de voz.

Solo necesita vincular una etiqueta compatible al perfil de colmena una vez y dejarla en colmena. Esto reduce el tiempo necesario para encontrar el perfil correcto y ayuda a mantener un historial más completo sin notas en papel separadas.

!!! info "Una nota de voz se convierte en texto"
    La aplicación hace más que guardar una grabación de voz: convierte la nota dictada en texto. Esto es especialmente conveniente cuando se trabaja con guantes protectores, durante el trabajo de cría o al inspeccionar muchas colmenas en secuencia. Posteriormente podrá revisar, buscar, procesar y copiar el texto cuando sea necesario.

## Etiquetas NFC vinculadas { #linked-nfc-tags }

Abierto **Menú principal → Configuración → Lista de etiquetas NFC** para ver los dispositivos o colmenas que la aplicación puede identificar vía NFC.

![Lista de dispositivos y colmenas vinculados vía NFC](../../assets/en/app/nfc-settings/linked-nfc-tags.jpg){ .doc-screenshot }

La lista muestra el nombre y el identificador de cada perfil vinculado. Al tocar el mosaico correspondiente, se elimina el enlace NFC.

!!! info "Lista de dispositivos y colmenas."
    En la lista de dispositivos y colmenas, un ícono NFC separado indica que hay una etiqueta vinculada. Se agregará un enlace directo a la descripción completa de esta pantalla una vez completada su revisión.

## Acción después del reconocimiento { #nfc-action }

Abierto **Menú principal → Configuración → Acción NFC** y seleccione lo que la aplicación debería abrir después de reconocer una etiqueta NFC.

![Seleccionar la acción realizada después de que se reconoce una etiqueta NFC](../../assets/en/app/nfc-settings/nfc-action-settings.jpg){ .doc-screenshot }

Acciones disponibles:

- **colmena abierta**;
- **Estado de colmena abierta**;
- **Evento colmena abierta**;
- **Evento + grabación de voz**.

La última opción abre inmediatamente la creación de eventos con entrada de voz después de que se identifica la colmena.
