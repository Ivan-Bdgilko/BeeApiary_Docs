# Eventos y notas

Los eventos le ayudan a mantener un historial de trabajo, inspecciones y observaciones de cada colmena. Para abrir la lista de eventos desde el [pantalla de inicio de la aplicación](main-screen.md), desliza hacia la derecha.

## Lista de eventos

La pantalla muestra la colmena seleccionada y sus eventos guardados. Cada entrada contiene un icono de tipo, nombre, marcador de color y fecha y hora. Toque **Insertar** para crear un evento o seleccione una entrada existente para editarla.

![Lista de eventos de la colmena seleccionada en la aplicación](../../assets/en/app/events-and-notes/events-list.jpg){ .doc-screenshot }

También puede crear eventos programados futuros. La aplicación te avisa con antelación para que el trabajo planificado no se pierda entre los registros actuales.

## Agregar o editar un evento

![Pantalla de edición de eventos en la aplicación.](../../assets/en/app/events-and-notes/event-editor.jpg){ .doc-screenshot }

| Elemento | Función |
|---|---|
| **Tipo de evento** | Determina el propósito, el icono y el marcador de color de la entrada. |
| **Fecha hora** | Registra cuándo ocurrió el evento o cuándo vence el trabajo planificado. |
| **Breve descripción** | Da un nombre corto a la acción completada o planificada. |
| **Descripción detallada** | Almacena información adicional, resultados de inspección o una nota. |
| **Guardar** | Guarda un nuevo evento o sus cambios. |
| **Eliminar** | Elimina el evento abierto. |

!!! note "Entrada de voz"
    Un campo marcado con un icono de micrófono admite el dictado. La aplicación convierte tu discurso en texto que puedes editar, buscar y copiar más tarde. No guarda una grabación de audio.

## Tipos de eventos

![Seleccionar un tipo de evento en la aplicación](../../assets/en/app/events-and-notes/event-type-options.jpg){ .doc-screenshot }

| Tipo | Cuando usarlo |
|---|---|
| **Inspección** | Registrar los resultados de una inspección de colmenas. |
| **Añadido** | Para indicar que se agregó algo a la colmena. |
| **Eliminado** | Para indicar que algo fue removido de la colmena. |
| **Advertencia** | Para eventos que requieren atención especial. |
| **Observación** | Registrar una condición o suceso observado. |

Los tipos de eventos tienen diferentes colores e íconos. en el [gráficos](charts.md), los eventos aparecen con marcas de tiempo y se ubican según el momento en que ocurrieron. Esto le ayuda a comparar el trabajo del apiario con cambios de peso, temperatura y otras medidas.
