# Instalación de la aplicación BeeApiary

## Instalación

!!! note "Permisos de aplicaciones"
    Recomendamos otorgar **todos los permisos** solicitado por la aplicación durante el primer lanzamiento. Si rechaza algunas de ellas, es posible que ciertas funciones no funcionen o funcionen incorrectamente; No se ha probado el comportamiento para cada combinación posible de restricciones. Para evitar dificultar innecesariamente la configuración y la resolución de problemas, conceda todos los permisos solicitados.

!!! warning "Se requiere permiso de SMS para GSM"
    si usas BeeApiary básculas de colmena y plan para recibir datos a través de GSM, se requiere permiso para procesar mensajes SMS. Sin él, la aplicación no puede leer los mensajes de la báscula, por lo que las mediciones no llegarán vía GSM.

    Si usas la aplicación sin BeeApiary básculas de colmena como cuaderno independiente y diario de apiario, no se requiere permiso por SMS.

1. Abre el [página de la aplicación en Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Instale e inicie la aplicación.
3. Otorgue todos los permisos solicitados por la aplicación.

!!! info "Sincronización automática a través de Bluetooth"
    Asegúrese de que la aplicación tenga permisos de Bluetooth y que el sistema le permita ejecutarse en segundo plano y activarse a la hora requerida. Procedimiento completo: [Configurar la sincronización vía Bluetooth](../guides/configure-bluetooth-sync.md).
