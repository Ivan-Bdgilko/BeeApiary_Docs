# Configuraciones de aplicaciones adicionales

Configuraciones adicionales controlan el filtrado de datos, la apariencia de la aplicación, la visualización de eventos y la sincronización local a través de Bluetooth.

![Configuraciones adicionales en el BeeApiary aplicación de Android](../../assets/en/app/additional-settings/app-additional-settings.jpg){ .doc-screenshot }

| Configuración | Función |
|---|---|
| **Filtrar picos altos** | Elimina picos de medición agudos ocasionales de la pantalla. |
| **Ver eventos** | Muestra eventos registrados para la colmena. |
| **Eventos por encima de las listas** | Afecta sólo a la vista gráfica y controla el orden de las capas: los eventos se dibujan sobre gráficos o los gráficos se dibujan sobre eventos, según el estado del interruptor. |
| **Modo nocturno permanente** | Mantiene el tema oscuro de la aplicación habilitado en todo momento. |
| **Mostrar sugerencias** | Muestra paneles de ayuda en las pantallas de la aplicación. |
| **Buscar dispositivos BLE** | Permite que la aplicación encuentre cerca BeeApiary básculas para colmenas y recibir los datos disponibles a través de Bluetooth. Para un funcionamiento correcto, [**BLE info**](../device/additional-settings.md) debe estar habilitado en cada báscula que desee sincronizar. |
| **Historia BLE** | Recibe un historial de mediciones más extenso junto con los datos actuales vía Bluetooth, hasta una semana dentro del historial disponible en el dispositivo. Esto es útil si visita el colmenar aproximadamente una vez por semana. |

Para las dos últimas configuraciones, siga las instrucciones completas. [Configurar la sincronización Bluetooth](../guides/configure-bluetooth-sync.md) guía.

!!! note "No confundas las dos pantallas"
    Esta página describe la configuración de la aplicación de Android. Opciones de hardware y canales de comunicación del BeeApiary Las básculas de colmena se describen en [Configuraciones adicionales del dispositivo](../device/additional-settings.md).
