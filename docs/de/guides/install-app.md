# So installierst du die BeeApiary-App

Die vollständige Anleitung zur Installation und zu den Berechtigungen findest du unter [BeeApiary-App installieren](../app/installation.md).

Die App funktioniert als eigenständiges Tagebuch oder empfängt Daten von der Waage. Für die Verarbeitung von SMS der Waage benötigt sie die SMS-Berechtigung.
