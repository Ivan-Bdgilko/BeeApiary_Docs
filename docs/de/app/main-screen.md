# Startbildschirm der App

Auf dem Startbildschirm werden der Gerätename, die letzten Werte, Datum und Uhrzeit der Messung sowie die Änderung im ausgewählten Zeitraum angezeigt. Tippe kurz auf die Überschrift, um die Diagramme zu öffnen, oder halte sie gedrückt, um die Einstellungen zu öffnen.
