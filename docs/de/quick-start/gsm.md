# Verbindung zum Gerät über GSM

!!! warning
    Verwende eine SIM-Karte im Format micro-SIM. Deaktiviere vorher die PIN-Abfrage der SIM-Karte.

    ![Vergleich der SIM-Kartenformate](../../assets/de/screenshots/device-quick-start-04.png){ .doc-photo }

1. [Installiere bei Bedarf die BeeApiary-App](app-only.md). Für den Empfang gewöhnlicher SMS ist sie nicht erforderlich. Wenn die App Messdaten aus SMS automatisch verarbeiten soll, ist die SMS-Berechtigung zwingend erforderlich.
2. Öffne den Deckel der Datenerfassungseinheit.

    ![Geöffnete Datenerfassungseinheit](../../assets/common/device-quick-start-01.png){ .doc-photo }

3. Setze die micro-SIM in den vorgesehenen Steckplatz ein.

    Richtige Position der Karte:

    ![Richtig eingesetzte micro-SIM](../../assets/common/device-quick-start-02.jpeg){ .doc-photo }

    Setze die SIM-Karte ein und drücke sie vorsichtig hinein, bis sie fast vollständig im Steckplatz versenkt ist und mit einem leichten Klicken einrastet:

    ![Im Steckplatz eingerastete micro-SIM](../../assets/common/device-quick-start-03.jpeg){ .doc-photo }

4. Aktiviere das Gerät oder starte es auf dieselbe Weise neu: Halte den Magnetschlüssel kurz an die Markenkennzeichnung auf der Rückseite der Haupteinheit.

    ![BeeApiary-Magnetschlüssel](../../assets/common/device-quick-start-05.png){ .doc-photo }

    ![Markenkennzeichnung für den Magnetschlüssel an der Haupteinheit](../../assets/common/device-quick-start-06.png){ .doc-photo }

5. Warte etwa eine Minute.
6. Prüfe, ob die erste SMS an der vorkonfigurierten Rufnummer ankommt.

Fertig: Das Gerät wurde aktiviert oder neu gestartet und kann Messwerte über GSM übertragen.

Wenn die Rufnummer des Besitzers noch nicht konfiguriert ist, [konfiguriere sie über das lokale WLAN](../guides/configure-gsm.md).
