# Як налаштувати пасічні ваги BeeApiary

1. Зарядіть пристрій через USB Type-C.

    !!! note "Вибір зарядного пристрою та кабелю"
        Пристрій не підтримує швидке заряджання, зокрема USB Power Delivery (PD). Використовуйте звичайне джерело живлення з портом USB Type-A та кабель USB Type-A–USB Type-C. Кабель USB Type-C–USB Type-C для заряджання не рекомендований.

2. Установіть пристрій і датчики згідно з [правилами розміщення](../device/placement.md).
3. Вставте micro-SIM із вимкненим PIN-кодом.

    Використовуйте саме формат micro-SIM:

    ![Порівняння форматів SIM-карток](../../assets/uk/quick-start/gsm/micro-sim-format-comparison.png){ .doc-photo }

    Правильно встановлена картка:

    ![Правильно встановлена micro-SIM](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    Вставте SIM-картку та обережно натисніть на неї, майже повністю зануривши у слот, доки не почуєте легке клацання, що підтверджує фіксацію:

    ![Фіксація micro-SIM у слоті](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

4. <span id="activation-reset"></span>Активуйте або перезапустіть пристрій: коротко піднесіть магнітний ключ до фірмової позначки на зворотному боці основного блока.

    ![Магнітний ключ BeeApiary](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

    ![Фірмова позначка зони магнітного ключа](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

5. Якщо потрібно перевірити або змінити налаштування, [підключіться до `apiary_net`](configure-local-wifi.md) і відкрийте `http://192.168.4.1`. Інакше цей крок можна пропустити.
6. Номер власника зазвичай уже налаштований виробником. Лише за потреби [перевірте, змініть або видаліть номер у налаштуваннях GSM](configure-gsm.md).
7. Якщо підключалися до `apiary_net`, від'єднайтеся від мережі. Дочекайтеся першого SMS: зазвичай воно надходить перед переходом пристрою в режим сну, приблизно через хвилину після від'єднання або активації.

    Після зміни налаштувань передавання, калібрування або інших налаштувань іноді потрібно дочекатися засинання пристрою та повторно активувати його магнітним ключем, не підключаючись знову до `apiary_net`.

Результат: пристрій збирає вимірювання, надсилає їх власнику та зберігає архів.
