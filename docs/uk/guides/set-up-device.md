# Як налаштувати новий вимірювальний пристрій BeeApiary

1. Зарядіть пристрій через USB Type-C.
2. Установіть пристрій і датчики згідно з [правилами розміщення](../device/placement.md).
3. Вставте micro-SIM із вимкненим PIN-кодом.

    Використовуйте саме формат micro-SIM:

    ![Порівняння форматів SIM-карток](../../assets/uk/screenshots/device-quick-start-04.png){ .doc-photo }

    Не вставляйте картку у слот у перевернутій орієнтації:

    ![Неправильна орієнтація SIM-картки](../../assets/common/device-quick-start-03.jpeg){ .doc-photo }

4. Активуйте або перезапустіть пристрій: коротко піднесіть магнітний ключ до фірмової позначки на зворотному боці основного блока.

    ![Магнітний ключ BeeApiary](../../assets/common/device-quick-start-05.png){ .doc-photo }

    ![Фірмова позначка зони магнітного ключа](../../assets/common/device-quick-start-06.png){ .doc-photo }

    Докладніше: [Активація та перезапуск](../device/installation.md#activation-reset).

5. Підключіться до `apiary_net` і відкрийте `http://192.168.4.1`.
6. Укажіть номер власника в міжнародному форматі.
7. Від'єднайтеся від `apiary_net` і перевірте перше SMS.

Результат: пристрій збирає вимірювання, надсилає їх власнику та зберігає архів.
