# Як оновити прошивку вимірювального пристрою BeeApiary

Перед оновленням виберіть прошивку, що відповідає поколінню пристрою та потрібній мові інтерфейсу.

## Виберіть покоління прошивки

| Пристрій | Джерело оновлень | Стан розвитку |
|---|---|---|
| Виготовлений до серпня 2026 року | [Hive_Controller](https://github.com/Ivan-Bdgilko/Hive_Controller) | Розширення функціональності попередньої версії більше не підтримується |
| Виготовлений після серпня 2026 року | [Hive_Controller_Ble](https://github.com/Ivan-Bdgilko/Hive_Controller_Ble) | Нова версія продовжує отримувати оновлення й розширення функціональності |

!!! danger "Перехід старого пристрою на нову версію"
    Будь-який раніше виготовлений пристрій можна перевести на нову версію програмного забезпечення, але для цього потрібне заводське оновлення. Простого патча для самостійного переходу наразі немає, тому звичайна процедура з цієї сторінки не виконує перехід між поколіннями.

## Виберіть мову прошивки

Обидва покоління мають багатомовні складання. Мову визначає суфікс у назві версії:

| Суфікс | Мова |
|---|---|
| `-de` | німецька |
| `-en` | англійська |
| `-es` | іспанська |
| `-fr` | французька |
| `-pl` | польська |
| `-uk` | українська |

Мову вибирають завантаженням і прошиванням відповідного файла. Мовні складання опубліковані у вільному доступі в зазначених вище репозиторіях і можуть надалі розширюватися новими мовами за потреби.

## Оновіть пристрій через microSD

1. Дочекайтеся, поки пристрій засне, і вийміть microSD.
2. У корені картки створіть каталог `/fm`, якщо його немає.
3. Помістіть файл оновлення `Apiary.bin` до `/fm`.
4. Поверніть microSD у пристрій.
5. [Активуйте або перезапустіть пристрій](../device/installation.md#activation-reset) магнітним ключем.
6. Дочекайтеся звичайного SMS із вимірюваннями; оновлення зазвичай триває до двох хвилин.
7. Унизу головної сторінки вебінтерфейсу перевірте версію прошивки, мовний суфікс, дату й час складання та унікальний номер пристрою.

![Версія прошивки, мовний суфікс, час складання та унікальний ID у вебінтерфейсі пристрою](../../assets/common/guides/update-device/device-version-build-time-and-id.png){ .doc-screenshot }

Повний рядок версії містить позначку локалізації, наприклад `-uk`. Звірте його з версією відповідного оновлення в репозиторії свого покоління пристрою. На цій самій сторінці також відображаються дата й час складання та унікальний ідентифікатор пристрою.

!!! warning "Перевірте файл перед оновленням"
    Переконайтеся, що `Apiary.bin` призначений для вашого покоління пристрою та потрібної мови. Сервісні способи оновлення через FTP або сервер не входять до цієї процедури.
