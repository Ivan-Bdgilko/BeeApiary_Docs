# Як установити застосунок BeeApiary

Повна інструкція з установлення та надання дозволів: [Встановлення застосунку BeeApiary](../app/installation.md).

Застосунок може працювати як автономний журнал або отримувати дані пасічних ваг. Для обробки SMS від ваг потрібний дозвіл на SMS.
