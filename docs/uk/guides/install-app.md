# Як установити застосунок BeeApiary

1. Відкрийте [BeeApiary у Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Натисніть **Установити**.
3. Запустіть застосунок.
4. Надайте дозвіл на обробку SMS.
5. Додайте пристрій і вкажіть номер установленої в ньому SIM-картки.

Результат: застосунок готовий приймати дані вимірювального пристрою BeeApiary. Докладніше: [Встановлення застосунку](../app/installation.md).
