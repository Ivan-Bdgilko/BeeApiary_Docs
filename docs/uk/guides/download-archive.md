# Як завантажити архів

Перед початком переконайтеся, що застосунок BeeApiary оновлено через Google Play. Номер установленої версії відображається внизу екрана інформації про пристрій:

![Номер версії застосунку внизу екрана інформації про пристрій](../../assets/uk/guides/download-archive/app-version-screen.png){ .doc-screenshot }

1. [Активуйте або перезапустіть вимірювальний пристрій BeeApiary](../device/installation.md#activation-reset) магнітним ключем.
2. Протягом доступного інтервалу, зазвичай близько однієї хвилини, підключіть телефон до `apiary_net` і залишайтеся поруч із пристроєм.
3. Відкрийте застосунок BeeApiary.
4. Дочекайтеся, поки застосунок автоматично знайде пристрій поруч.
5. У запиті **«Пристрій поруч. Забрати архів?»** натисніть **Так**.

    ![Запит дозволу забрати архів із пристрою поруч](../../assets/uk/guides/download-archive/download-archive-confirmation.png){ .doc-screenshot }

6. Дочекайтеся завершення імпорту, а потім від'єднайтеся від `apiary_net`.
7. Перегляньте завантажені дані стандартними засобами застосунку.

    ![Вимірювання з імпортованого архіву пристрою](../../assets/uk/guides/download-archive/imported-archive-measurements.png){ .doc-screenshot }

Результат: після підтвердження застосунок автоматично забирає архів і зберігає локальну копію вимірювань. Формат архіву описано в [Зберіганні даних](../system/data-storage.md).
