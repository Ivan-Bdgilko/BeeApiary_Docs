# Налаштування системи

!!! danger "Увага: пристрій уже повністю налаштований"
    Новий вимірювальний пристрій BeeApiary постачається налаштованим і відкаліброваним. Номер користувача вже записаний у пристрої, тому додатково перелаштовувати його не потрібно.

    Будь ласка, не робіть нічого на власний розсуд. Зазвичай достатньо виконати лише перші чотири кроки нижче — і все працює.

    Не виймайте батарею, не таруйте, не калібруйте й не змінюйте налаштування, не дочитавши відповідну інструкцію до кінця. Робити це під час першого запуску категорично не рекомендується.

!!! warning "Перед установленням SIM-картки"
    Використовуйте лише micro-SIM і заздалегідь вимкніть захист PIN-кодом.

1. Відкрийте кришку блока збирання даних.

    ![Відкритий блок збирання даних](../../assets/common/device/installation/open-data-collection-unit.png){ .doc-photo }

2. Встановіть micro-SIM у відповідний слот.

    Правильне положення картки:

    ![Правильно встановлена micro-SIM](../../assets/common/device/installation/micro-sim-insertion-orientation.jpeg){ .doc-photo }

    Вставте SIM-картку та обережно натисніть на неї, майже повністю зануривши у слот, доки не почуєте легке клацання, що підтверджує фіксацію:

    ![Фіксація micro-SIM у слоті](../../assets/common/device/installation/micro-sim-locked-in-slot.jpeg){ .doc-photo }

3. [Активуйте або перезапустіть пристрій](../device/installation.md#activation-reset): коротко піднесіть магнітний ключ до фірмової позначки на зворотному боці основного блока.

    ![Магнітний ключ BeeApiary](../../assets/common/device/installation/magnetic-key.png){ .doc-photo }

    ![Фірмова позначка зони магнітного ключа](../../assets/common/device/installation/magnetic-key-target.png){ .doc-photo }

4. Зачекайте приблизно одну хвилину та перевірте надходження першого SMS на попередньо налаштований номер користувача.

Готово. Вітаємо, ви впоралися: пристрій збирає дані, надсилає їх через GSM і зберігає локальний архів.

## Застосунок — за потреби

Для отримання звичайних SMS застосунок BeeApiary не обов'язковий. Установіть його, якщо хочете автоматично приймати дані пристрою, переглядати вимірювання та користуватися іншими функціями застосунку.

1. [Установіть застосунок BeeApiary](app-only.md) і обов'язково надайте йому дозвіл на обробку SMS.
2. У застосунку виберіть **Додати пристрій**.
3. Введіть номер micro-SIM, установленої у вимірювальному пристрої BeeApiary.

!!! note
    У поле пристрою вводьте номер установленої в ньому SIM-картки, а не номер телефону користувача.

Якщо перше SMS не надійшло, не змінюйте налаштування навмання. Скористайтеся сторінкою [Не надходять SMS](../troubleshooting/no-sms.md). Номер користувача змінюйте через [налаштування GSM](../guides/configure-gsm.md) лише за потреби.
