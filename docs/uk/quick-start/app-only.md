# Тільки застосунок BeeApiary

1. Відкрийте [BeeApiary у Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Встановіть застосунок. У Google Play його також можна знайти за назвою **Beekeeper notes**.
3. Запустіть застосунок.
4. Надайте застосунку дозвіл на обробку SMS.
5. За потреби додайте пристрій і вкажіть номер SIM-картки, встановленої в ньому.

Готово: застосунок установлено. Дані від вимірювального пристрою BeeApiary з'являться після [налаштування GSM](gsm.md).

Докладніше: [Встановлення застосунку](../app/installation.md).
