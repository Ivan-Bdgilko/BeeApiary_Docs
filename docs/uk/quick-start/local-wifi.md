# Швидке підключення до локальної мережі Wi-Fi

1. [Активуйте або перезапустіть пристрій](../device/installation.md#activation-reset): коротко піднесіть магнітний ключ до фірмової позначки на зворотному боці основного блока.
2. Протягом хвилини відкрийте список Wi-Fi-мереж на телефоні, планшеті або ноутбуці.
3. Підключіться до мережі `apiary_net` із початковим паролем `apiary_wifi`.
4. Відкрийте адресу [http://192.168.4.1](http://192.168.4.1).
5. Переконайтеся, що відображається головна сторінка пристрою.
6. Після завершення налаштувань від'єднайтеся від `apiary_net`.

Готово: вебінтерфейс пристрою доступний без доступу до Інтернету.

!!! warning "Безпека"
    Після першої перевірки змініть початковий пароль Wi-Fi. Докладніше: [Локальна мережа Wi-Fi](../system/local-wifi.md).
