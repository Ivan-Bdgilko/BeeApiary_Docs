# Зв'язок із пристроєм через GSM

Щоб установити micro-SIM, активувати ваги та отримати перше SMS, перейдіть до [налаштування системи](full-system.md).

Для звичайних SMS застосунок не потрібний. Якщо хочете обробляти SMS у застосунку, надайте йому дозвіл на SMS.
