# Журнали

Вимірювальний пристрій BeeApiary має три різні види даних:

1. архів вимірювань для користувача у CSV;
2. службовий журнал роботи пристрою на microSD;
3. інженерний журнал у реальному часі через вебінтерфейс.

Службові журнали потрібні для діагностики, а не для звичайного перегляду. Вони доступні на microSD; вебінтерфейс також містить службові адреси `/log` і `/tracecontrol`.

!!! warning
    Не змінюйте глибину інженерного логування без потреби або рекомендації розробника. Для аналізу вимірювань використовуйте [архів даних](data-storage.md).
