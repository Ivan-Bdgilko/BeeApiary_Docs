# Як працює система

Пасічні ваги BeeApiary разом із датчиками та застосунком утворюють розумний вулик BeeApiary. Ваги вимірюють і локально зберігають дані, а застосунок BeeApiary для Android приймає, зберігає та відображає їх користувачу.

Дані можуть надходити до застосунку через GSM, пряме Wi-Fi-з'єднання з пристроєм, маршрутизацію через Wi-Fi мережу пасіки або Bluetooth. Для основної роботи система не потребує обов'язкового зовнішнього сервера, а транзитний онлайн-механізм не зберігає дані.
