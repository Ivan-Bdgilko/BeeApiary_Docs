# Потік даних

1. На початку години вимірювальний пристрій BeeApiary виконує налаштовані вимірювання.
2. Результат зберігається в локальному архіві microSD, якщо картка доступна.
3. Відповідно до розкладу пристрій формує SMS. Одне стисле SMS може містити дані за кілька попередніх годин.
4. Застосунок BeeApiary для Android отримує SMS, розпізнає значення й додає їх до локального сховища телефона.
5. Користувач переглядає поточні значення, історію та графіки.

Окремо застосунок може завантажити річний архів безпосередньо через локальну мережу пристрою. Основний збір вимірювань не припиняється через відсутність GSM або доступу до Інтернету.
