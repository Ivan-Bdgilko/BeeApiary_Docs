# Як дані з вулика потрапляють на телефон { #_1 }

Моніторинг вулика BeeApiary охоплює вимірювання, локальне зберігання та передавання даних до застосунку. Нижче показано шлях від вимірювання на пристрої до поточних значень, історії та графіків на телефоні.

1. На початку години пасічні ваги BeeApiary виконують налаштовані вимірювання.
2. Результат зберігається в локальному архіві microSD, якщо картка доступна.
3. Пристрій робить дані доступними через налаштований канал:

    - надсилає звичайне або стисле SMS за розкладом;
    - маршрутизує дані через Wi-Fi мережу пасіки;
    - [передає доступні дані через Bluetooth](bluetooth.md), коли телефон перебуває поруч;
    - надає архів застосунку через власну точку доступу після підтвердження користувача.

4. Застосунок розпізнає отримані значення й додає їх до локального сховища телефона.
5. Користувач переглядає поточні значення, історію та графіки.

Відсутність GSM, Wi-Fi, Bluetooth або телефона поруч не припиняє основний збір вимірювань. Коли зв'язок стане доступним, дані можна передати до застосунку.

За віддаленої маршрутизації через Wi-Fi транзитний онлайн-механізм не зберігає дані. Постійні копії залишаються у пам'яті пасічних ваг BeeApiary та на телефоні користувача.

Порівняння каналів: [Отримання даних у застосунку](connectivity.md).

Налаштування віддаленого каналу: [Синхронізація через Wi-Fi мережу пасіки](../guides/configure-wifi-sync.md).

Налаштування локального автоматичного каналу: [Синхронізація через Bluetooth](../guides/configure-bluetooth-sync.md).
