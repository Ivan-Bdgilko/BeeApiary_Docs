# Способи зв'язку

## GSM і SMS

Основний віддалений канал. Пристрій надсилає звичайні або стислі SMS без проміжного сервера BeeApiary. Докладніше: [GSM та SMS](gsm-and-sms.md).

## Локальна мережа Wi-Fi

Пристрій створює локальну точку доступу для вебінтерфейсу, FTP і прямого завантаження архіву. Доступ до Інтернету не потрібен. Докладніше: [Локальна мережа Wi-Fi](local-wifi.md).

## BLE

BLE зазначено в технічних характеристиках як доступний канал зв'язку. Наявні джерела не містять перевіреної процедури підключення чи передачі даних через BLE, тому окрема інструкція не публікується.

## Робота без зв'язку

Пристрій може продовжувати вимірювання та запис на microSD без SIM і без доступу до Інтернету. Дані можна забрати пізніше через локальну мережу Wi-Fi або безпосередньо з картки.
