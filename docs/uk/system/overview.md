# Як працює система

BeeApiary складається з вимірювального пристрою, який вимірює й зберігає дані, та застосунку BeeApiary для Android, який приймає, зберігає і відображає їх користувачу.

Система не потребує зовнішнього сервера BeeApiary для основної роботи. Дані можуть передаватися безпосередньо через SMS або завантажуватися з пристрою через локальну мережу Wi-Fi.
