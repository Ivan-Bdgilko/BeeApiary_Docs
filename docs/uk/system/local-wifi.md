# Локальна мережа Wi-Fi

Після перезапуску вимірювальний пристрій BeeApiary тимчасово створює локальну точку доступу. Початкові параметри з джерела:

```text
SSID: apiary_net
Пароль: apiary_wifi
Вебінтерфейс: http://192.168.4.1
```

Через локальне з'єднання можна:

- відкрити вебінтерфейс;
- налаштувати номер власника й розклад;
- переглянути заряд та версію прошивки;
- завантажити архів;
- скористатися FTP для файлів microSD.

!!! warning "Змініть пароль"
    Початковий пароль опублікований у попередній документації. Після першої перевірки встановіть власний пароль довжиною до 32 символів.

Докладна процедура: [Налаштувати локальну мережу Wi-Fi](../guides/configure-local-wifi.md).
