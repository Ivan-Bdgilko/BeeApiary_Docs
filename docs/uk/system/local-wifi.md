# Wi-Fi ваги для вулика — пряме та мережеве підключення { #wi-fi- }

Пасічні ваги BeeApiary з Wi-Fi підтримують два способи отримання даних: пряме підключення телефона до точки доступу пристрою (AP) та передавання через Wi-Fi мережу пасіки (STA). Перший спосіб працює поруч із вагами, а другий дає змогу отримувати дані віддалено за наявності Інтернету.

## Пряме підключення до пристрою { #direct-access-point }

Після активації магнітним ключем пристрій тимчасово створює локальну точку доступу. Вона зазвичай доступна близько однієї хвилини, але цей інтервал можна змінити в налаштуваннях.

Початкові параметри:

```text
SSID: apiary_net
Пароль: apiary_wifi
Вебінтерфейс: http://192.168.4.1
```

Через локальне з'єднання можна:

- дозволити застосунку забрати архів вимірювань;
- відкрити вебінтерфейс;
- налаштувати номер власника й розклад;
- переглянути заряд та версію прошивки;
- скористатися FTP для файлів microSD.

Після підключення телефона до `apiary_net` застосунок знаходить пристрій і показує запит **«Пристрій поруч. Забрати архів?»**. Дані завантажуються лише після підтвердження користувача.

!!! warning "Змініть пароль"
    Початковий пароль є загальновідомим. Після першої перевірки встановіть власний пароль довжиною до 32 символів.

Докладні процедури:

- [Підключитися до точки доступу пристрою](../guides/configure-local-wifi.md);
- [завантажити архів у застосунок](../guides/download-archive.md);
- [переглянути додаткові налаштування пристрою](../device/additional-settings.md).

## Маршрутизація через Wi-Fi мережу пасіки { #apiary-wifi-routing }

Пристрій може підключатися до наявної Wi-Fi мережі на пасіці та автоматично передавати дані через Інтернет до застосунку власника. Телефон може перебувати будь-де, де має доступ до Інтернету.

Для цього способу не потрібна окрема SIM-картка в кожному пристрої, але біля пристрою мають бути налаштована Wi-Fi мережа й доступ до Інтернету.

### Як працює налаштування

Спочатку користувач реєструє в застосунку вже відомий йому пристрій. Під час реєстрації телефон повинен мати доступ до Інтернету, але підключення до самого пристрою ще не потрібне. Сервіс створює ідентифікатори та ключі для взаємодії застосунку з пристроєм.

Після цього користувач задає в застосунку назву й пароль Wi-Fi мережі пасіки. Застосунок зберігає налаштування на телефоні, але пристрій ще не має їх. Для передавання потрібно тимчасово підключити телефон до точки доступу `apiary_net`, повернутися в застосунок і погодитися записати підготовлені налаштування у пристрій.

Після перезапуску магнітним ключем або під час наступного запланованого годинного циклу пристрій використовує задану мережу для автоматичного передавання. Телефон більше не повинен перебувати поруч.

### Передумови

- пристрій уже додано до застосунку;
- застосунок хоча б раз отримав його дані через SMS або пряме завантаження архіву;
- телефон має Інтернет під час реєстрації;
- біля пристрою доступна Wi-Fi мережа з Інтернетом;
- користувач знає назву та пароль цієї мережі.

Транзитний онлайн-механізм не зберігає дані. Постійне зберігання відбувається локально у пам'яті пасічних ваг BeeApiary та на телефоні користувача.
