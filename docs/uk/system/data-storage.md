# Зберігання даних

Вимірювальний пристрій BeeApiary записує дані на microSD незалежно від того, чи доступний GSM. Для кожного року створюється каталог `YEARxx`, а для місяців — CSV-файли з датою, часом і доступними показниками.

CSV може містити:

- `Date`, `Time`;
- `Weight[Kg]`;
- `T1 [°C]`, `T2 [°C]` та додаткові температури;
- заряд батареї;
- тиск і вологість;
- GSM RSSI;
- службові метадані прошивки.

Склад стовпців залежить від комплектації та версії прошивки. Вимірювання займають приблизно 2 МБ на рік, а службові журнали — близько 40-50 МБ на рік.
