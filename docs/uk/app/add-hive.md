# Додати вулик

Профіль вулика можна використовувати без пасічних ваг BeeApiary. Він дає змогу вести описи, фіксувати стан вулика, створювати нотатки та записувати заплановані й виконані події. Дозвіл на SMS для такого сценарію не потрібний.

1. Відкрийте головне меню застосунку.
2. Виберіть **Додати пристрій чи вулик**.
3. Оберіть створення профілю вулика.
4. Додайте відому інформацію про вулик і збережіть профіль.

Після створення профілю використовуйте сторінки [Події та нотатки](events-and-notes.md) і [Стан вулика](hive-state.md) для подальшої роботи.

!!! note "Подальше рев'ю"
    Сторінку буде доповнено перевіреною послідовністю екранів і назвами полів після окремого огляду сценарію додавання вулика.
