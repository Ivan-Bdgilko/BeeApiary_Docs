# Додати вулик

Створіть профіль вулика без фізичних пасічних ваг, щоб вести його щоденник, фіксувати стан, додавати нотатки та записувати заплановані й виконані події. Для такого сценарію не потрібні пасічні ваги, SIM-картка або дозвіл на обробку SMS.

1. Відкрийте **Головне меню → Додати пристрій чи вулик**.
2. На екрані **Пристрої та вулики** натисніть **Додати вулик**.
3. Уведіть назву, за якою зможете легко знайти цей вулик.
4. Натисніть **Додати**.

    ![Форма додавання профілю вулика без пасічних ваг](../../assets/uk/app/add-hive/add-hive-form.jpg){ .doc-screenshot }

Після збереження профіль з'явиться у спільному списку пристроїв і вуликів. Використовуйте розділи [Стан вулика](hive-state.md) і [Події та нотатки](events-and-notes.md), щоб поступово формувати його історію.
