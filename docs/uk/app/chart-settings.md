# Вибір даних і графіків

Ці налаштування визначають, які вимірювання відображаються на головному екрані та у вигляді графіків, а також задають порядок їх показу.

1. Відкрийте **Головне меню → Налаштування → Діаграми**.
2. Увімкніть потрібні типи вимірювань: температуру, вагу, батарею тощо.
3. Змініть порядок за допомогою стрілок праворуч від типів вимірювань.
4. За потреби ввімкніть фільтрацію випадкових хибних значень.

![Вибір даних і порядку графіків](../../assets/uk/app/chart-settings/chart-settings.png){ .doc-screenshot }

Після повернення на [головний екран](main-screen.md) і сторінку [графіків](charts.md) застосунок використовуватиме вибраний набір та порядок показників.
