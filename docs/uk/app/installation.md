# Встановлення застосунку BeeApiary

## Встановлення

!!! note "Дозволи застосунку"
    Під час першого запуску рекомендуємо надати **всі дозволи**, які запитує застосунок. Якщо відхилити частину з них, деякі функції можуть не працювати або працювати неправильно; поведінку для всіх можливих комбінацій обмежень не перевірено. Щоб не ускладнювати налаштування та пошук причин проблем, надайте всі запитані дозволи.

!!! warning "Для GSM дозвіл на SMS обов'язковий"
    Якщо ви використовуєте пасічні ваги BeeApiary і плануєте отримувати дані через GSM, дозвіл на обробку SMS є обов'язковим. Без нього застосунок не зможе прочитати повідомлення від ваг, тому вимірювання через GSM не надходитимуть.

    Якщо застосунок використовується без пасічних ваг BeeApiary як автономний записник і журнал пасіки, дозвіл на SMS не потрібний.

1. Відкрийте [сторінку застосунку в Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. Установіть і запустіть застосунок.
3. Надайте всі дозволи, які запитує застосунок.

!!! info "Автоматична синхронізація через Bluetooth"
    Переконайтеся, що застосунку надані дозволи Bluetooth, а система дозволяє йому працювати у фоні та прокидатися у потрібний час. Повна процедура: [Налаштувати синхронізацію через Bluetooth](../guides/configure-bluetooth-sync.md).

## Наступні кроки

Після встановлення оберіть потрібний сценарій:

- [Додайте пасічні ваги BeeApiary](add-device.md), щоб отримувати автоматичні вимірювання.
- [Додайте вулик](add-hive.md), щоб вести його опис, стан, нотатки й події навіть без фізичного пристрою.

Попередні APK у [репозиторії Android_Apk](https://github.com/Ivan-Bdgilko/Android_Apk) застарілі. Для актуального встановлення використовуйте Google Play.
