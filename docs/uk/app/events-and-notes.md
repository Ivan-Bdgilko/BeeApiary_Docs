# Події та нотатки

Вихідний посібник користувача підтверджує наявність подій і додаткової фільтрації, але позначає їхній опис як такий, що перебуває в розробці.

Ця сторінка буде доповнена після отримання перевірених сценаріїв використання. Поточну поведінку не слід виводити лише з інтерфейсу застосунку.
