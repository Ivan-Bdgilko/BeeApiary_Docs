# Графіки

!!! warning "Сторінка оновлюється"
    Перепрошуємо: ця сторінка ще не пройшла остаточне рев'ю. Частина інформації може бути застарілою або неповною, оскільки відповідний розділ документації чи описана функціональність програмного забезпечення зараз активно розробляється.

Графіки будуються лише для числових показників, значення яких змінюються з часом: наприклад, ваги, температури, вологості, тиску або заряду батареї. Текстові описи стану вулика й події залишаються окремими блоками [головного екрана](main-screen.md).

Після вибору періоду та кінцевої дати застосунок перебудовує активні графіки для заданого проміжку:

![Графіки за вибраний період](../../assets/uk/app/charts/selected-period-charts.png){ .doc-screenshot }

Набір і порядок графіків залежать від вибраних плиток та налаштувань відображення.

- [Вибрати період і кінцеву дату](chart-period.md)
- [Вибрати дані, графіки та їх порядок](chart-settings.md)
