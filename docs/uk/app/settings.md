# Налаштування застосунку

Застосунок дає змогу:

- додавати вимірювальний пристрій BeeApiary за номером його SIM-картки;
- вибирати показники та порядок графіків;
- фільтрувати випадкові хибні вимірювання;
- змінювати період перегляду даних;
- працювати із завантаженим архівом пристрою;
- реєструвати пристрій і готувати налаштування для синхронізації через Wi-Fi мережу пасіки;
- вмикати пошук пристроїв та отримання історії через Bluetooth.

Налаштування самого пристрою через локальний вебінтерфейс описані окремо: [Пряме Wi-Fi-з'єднання з пристроєм](../system/local-wifi.md#direct-access-point).

Реєстрація й передавання підготовлених параметрів: [Налаштувати синхронізацію через Wi-Fi мережу пасіки](../guides/configure-wifi-sync.md).

Пошук пристроїв, отримання даних та історії: [Налаштувати синхронізацію через Bluetooth](../guides/configure-bluetooth-sync.md).
