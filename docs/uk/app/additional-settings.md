# Додаткові налаштування застосунку

Додаткові налаштування керують фільтрацією даних, виглядом застосунку, показом подій і локальною синхронізацією через Bluetooth.

![Додаткові налаштування Android-застосунку BeeApiary](../../assets/uk/app/additional-settings/app-additional-settings.png){ .doc-screenshot }

| Параметр | Призначення |
|---|---|
| **Фільтрувати хибні виміри** | Прибирає з відображення випадкові різкі викиди показників. |
| **Відображати події** | Показує події, записані для вулика. |
| **Події вище діаграм** | Змінює лише графічне подання та визначає порядок шарів: події промальовуються поверх графіків або графіки поверх подій залежно від стану перемикача. |
| **Постійний нічний режим** | Залишає темну тему застосунку ввімкненою постійно. |
| **Відображати підказки** | Показує довідкові блоки на екранах застосунку. |
| **Сканувати пристрої BLE** | Дозволяє шукати пасічні ваги BeeApiary поруч і отримувати від них доступні дані через Bluetooth. Для правильної роботи на кожних вагах, з якими потрібно синхронізуватися, має бути ввімкнено [параметр **BLE info**](../system/additional-settings.md). |
| **Історія з BLE** | Дозволяє разом із поточними даними отримувати через Bluetooth історію вимірювань за більший проміжок, до одного тижня в межах доступних даних пристрою. Це зручно, якщо ви відвідуєте пасіку приблизно раз на тиждень. |

Для двох останніх параметрів виконайте повну інструкцію [Налаштувати синхронізацію через Bluetooth](../guides/configure-bluetooth-sync.md).

!!! note "Не плутайте два екрани"
    Ця сторінка описує налаштування Android-застосунку. Апаратні параметри й канали передавання самих пасічних ваг описано на сторінці [Додаткові налаштування пристрою](../system/additional-settings.md).
