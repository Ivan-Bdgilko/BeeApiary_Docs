# Стан вулика

У джерелі перелічені поля стану вулика:

- поточний стан розплоду та бджіл;
- порода й плодючість матки;
- кількість різних типів рамок;
- рівень кліща та агресії.

Опис функції в посібнику користувача позначено як такий, що перебуває в розробці. Інструкцію буде додано після перевірки поведінки актуальної версії застосунку.
