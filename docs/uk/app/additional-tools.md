# Додаткові інструменти

Підменю **Додаткові інструменти** містить команди для резервного копіювання даних і сервісної діагностики.

![Меню додаткових інструментів застосунку BeeApiary](../../assets/uk/app/additional-tools/additional-tools-menu.png){ .doc-screenshot }

| Команда | Призначення |
|---|---|
| **Зберегти дані (резервна копія)** | Створює резервну копію бази даних застосунку. |
| **Відновити дані** | Відновлює дані застосунку з раніше створеної резервної копії. |
| **Зберегти файл логування** | Зберігає файл службового журналу, який можна передати сервісній підтримці для діагностики. |

!!! warning "Зберігайте актуальну резервну копію"
    Перед відновленням переконайтеся, що вибрано потрібну копію даних. Збережіть поточну резервну копію окремо, якщо її ще може знадобитися повернути.
