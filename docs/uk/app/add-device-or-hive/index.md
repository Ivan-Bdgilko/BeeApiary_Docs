# Додати ваги або вулик

Екран **Пристрої та вулики** дає змогу:

- додати фізичні пасічні ваги BeeApiary до профілю вулика;
- створити профіль вулика без обладнання;
- запустити демонстраційний сценарій вулика з вагами й тестовими даними для ознайомлення.

![Вибір додавання пасічних ваг, вулика або тестових даних](../../../assets/uk/app/add-device-or-hive/add-scales-hive-or-test-data.jpg){ .doc-screenshot }

## Пасічні ваги BeeApiary

Кнопка **Додати пристрій** створює профіль вулика, пов'язаний із фізичними пасічними вагами BeeApiary. Такий профіль може автоматично отримувати вимірювання ваги, температури та інших доступних показників.

Продовжуйте на сторінці [Додати пасічні ваги BeeApiary](../add-device.md). Порівняти GSM, пряме Wi-Fi-з'єднання, Wi-Fi мережу пасіки та Bluetooth можна в розділі [Отримання даних у застосунку](../../system/connectivity.md).

## Вулик без ваг

Кнопка **Додати вулик** створює окремий профіль без фізичних ваг. Для нього можна вести щоденник, описувати [стан вулика](../hive-state.md), додавати нотатки та фіксувати [події](../events-and-notes.md).

Продовжуйте на сторінці [Додати вулик](../add-hive.md).

## Тестовий вулик із симульованими вагами

Кнопка **Додати тестові дані** створює демонстраційний вулик з емулятором пасічних ваг. Застосунок формує наближені до реальних дані, тому можна переглядати головний екран, графіки, стани й події та працювати з ними так само, як із профілем реальних смартваг.

Тестові значення призначені лише для знайомства з можливостями застосунку й не є реальними вимірюваннями.

## Додаткові інструкції

У нижній частині екрана розміщені переходи до відеоінструкцій YouTube і посібника користувача. Вони допомагають перейти від короткого вибору сценарію до докладного налаштування.
