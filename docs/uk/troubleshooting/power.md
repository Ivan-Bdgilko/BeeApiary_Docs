# Проблеми живлення

1. Підключіть справне джерело USB Type-C і дайте батареї зарядитися.
2. Перевірте, що у вимірювальному пристрої BeeApiary встановлений щонайменше один елемент 18650.
3. Якщо батарею замінювали, перевірте полярність за позначеннями тримача.
4. Після критичного розряду дочекайтеся відновлення заряду; пристрій може повернутися до звичайної роботи з наступного циклу.
5. Після відновлення перевірте й за потреби синхронізуйте час.

!!! danger
    Не намагайтеся живити пристрій лише від зовнішнього USB без елемента 18650. Неправильна полярність батареї може необоротно пошкодити пристрій.
