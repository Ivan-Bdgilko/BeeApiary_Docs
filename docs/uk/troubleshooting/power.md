# Проблеми живлення

!!! note "Заряджання"
    Пристрій не підтримує швидке заряджання, зокрема USB Power Delivery (PD). Для перевірки використовуйте звичайне джерело живлення з портом USB Type-A та кабель USB Type-A–USB Type-C. Кабель USB Type-C–USB Type-C не рекомендований.

1. Після тривалого зберігання перевірте напругу батареї. Якщо вона нижча за `3,5 В`, виконайте [процедуру відновлення після зберігання](recovery-after-storage.md).
2. В інших випадках підключіть справне звичайне джерело живлення до роз'єму USB Type-C і дайте батареї зарядитися.
3. Перевірте, що у вимірювальному пристрої BeeApiary встановлений щонайменше один елемент 18650.
4. Якщо батарею замінювали, перевірте полярність за позначеннями тримача.
5. Після критичного розряду дочекайтеся відновлення заряду; пристрій може повернутися до звичайної роботи з наступного циклу.
6. Після відновлення перевірте й за потреби синхронізуйте час.

!!! danger
    Не намагайтеся живити пристрій лише від зовнішнього USB без елемента 18650. Неправильна полярність батареї може необоротно пошкодити пристрій.
