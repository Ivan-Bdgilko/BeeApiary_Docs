# Не вдається підключитися до Wi-Fi

1. [Активуйте або перезапустіть вимірювальний пристрій BeeApiary](../device/installation.md#activation-reset): коротко піднесіть магнітний ключ до фірмової позначки на зворотному боці основного блока.
2. Шукайте мережу протягом першої хвилини після перезапуску.
3. Перевірте SSID; початкове значення — `apiary_net`.
4. Перевірте пароль; початкове значення — `apiary_wifi`, якщо його не змінювали.
5. Після підключення вручну відкрийте `http://192.168.4.1`.
6. Якщо сторінка не відкривається, вимкніть мобільні дані або автоматичне перемикання на Інтернет для цієї локальної сесії й повторіть спробу.

Якщо хвилина минула, повторіть те саме коротке піднесення ключа до позначки. Докладніше: [Локальна мережа Wi-Fi](../system/local-wifi.md).
