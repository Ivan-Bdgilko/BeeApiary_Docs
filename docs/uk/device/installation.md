# Як встановити пасічні ваги під вулик { #_1 }

Для встановлення ваг під вулик розмістіть основний блок у захищеному місці, а вагові датчики — на твердих опорах.

1. Виберіть захищене місце під козирком або кришкою вулика.
2. Розмістіть основний блок так, щоб на нього якнайменше потрапляли пряме сонце, дощ і сніг.
3. Установіть [вагові датчики](sensors.md) на тверді опори в одній горизонтальній площині.
4. Розмістіть температурні датчики відповідно до задачі спостереження.

!!! danger
    Не розміщуйте пристрій або виносну антену в найвищій точці пасіки: це створює ризик ураження блискавкою та неремонтопридатного пошкодження.

Докладніше: [Розміщення](placement.md) і [Датчики](sensors.md).
