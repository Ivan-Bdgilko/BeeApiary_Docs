# Сервісна документація

Цей розділ є технічним архівом конфігурації вимірювального пристрою BeeApiary. Він призначений для сервісних спеціалістів і досвідчених користувачів, яким потрібно відновити або перевірити XML-файли вручну.

Початкові значення деяких апаратних і мережевих параметрів залежать від комплектації та налаштування конкретного пристрою.

!!! danger "Ручне редагування"
    Помилкові апаратні контакти, калібрувальні значення або службові інтервали можуть порушити вимірювання чи роботу пристрою. Для звичайних змін використовуйте вебінтерфейс. Перед ручним редагуванням обов'язково створіть резервну копію каталогу `/setting`.

## Безпечний порядок роботи

1. Дочекайтеся, поки пристрій засне. Пристрій не має штатної кнопки вимкнення: під час роботи він перебуває в активному режимі або в режимі гібернації.
2. Вийміть microSD і збережіть повну копію каталогу `/setting`.
3. Редагуйте XML у текстовому редакторі без зміни назв секцій та атрибутів.
4. Переконайтеся, що XML має один кореневий елемент `<settings>`, усі лапки й закривальні теги на місці.
5. Поверніть microSD, поки пристрій спить. Оновлені налаштування застосовуються після наступного штатного запуску конфігурації; частина змін, зроблених через вебінтерфейс, також набуває чинності лише після перезапуску.
6. Перевірте вимірювання, зв'язок і службовий журнал. Збережіть резервну копію до завершення перевірки.

Під час збереження пристрій може нормалізувати файл: додати відсутні секції або атрибути, підставити резервні значення та переписати порядок елементів.

## Файли

- [`/setting/mset.xml`](settings-reference.md) — мережа, GSM, час, апаратні опції, аларми загального рівня та BLE.
- [`/setting/<hive>.xml`](hive-settings-reference.md) — датчики конкретного вулика, вага, розклад, частота перевірок і порогові аларми.
- [Відновлення конфігурації](recovery.md) — безпечна заміна microSD, відновлення з резервної копії та перевірка XML.

Ім'я файла вулика задається атрибутом `hive1`, `hive2` тощо без розширення. Розширення `.xml` додається автоматично.

## Рівні доступу

| Позначення | Значення |
|---|---|
| `USER` | Значення можна змінювати через штатний інтерфейс. |
| `ADVANCED` | Потрібне розуміння впливу на зв'язок або логіку роботи. |
| `SERVICE` | Ручна зміна може зробити пристрій непрацездатним або спотворити дані. |

У таблицях `—` означає, що межі для поля не застосовуються. **Початкове значення** — значення в новоствореній конфігурації, а не в XML конкретного пристрою. **Якщо не задано** описує значення, яке використовується за відсутності атрибута, і воно може відрізнятися від початкового.

## Історичні назви

Точні ідентифікатори XML не виправляються, навіть якщо містять помилки: `apairy_set`, `sefe_start_interval`, `normal_pecision` і `calibrate_pecision` мають залишатися саме такими. Написання `synсhronize` з кириличною літерою `с` є помилковим; використовуйте `synchronize`.
