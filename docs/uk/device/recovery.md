# Відновлення конфігурації

Ця сторінка описує безпечну заміну microSD, відновлення конфігурації з резервної копії та перевірку XML після запуску пристрою.

!!! danger "Не виймайте microSD під час активної роботи"
    Пристрій не має штатної кнопки вимкнення. Перед вийманням або встановленням microSD дочекайтеся, поки пристрій засне. Спочатку збережіть повну копію каталогу `/setting`.

## Автоматична нормалізація

- основний файл має шлях `/setting/mset.xml`;
- якщо основного файла немає, пристрій може створити початкову конфігурацію;
- відсутній або неповний файл вулика може бути збережений заново з резервними значеннями поточного стану;
- відсутні `hive`, `thermometer` або `schedule`, а також неповна наявна секція `scales`, запускають нормалізацію файла вулика;
- відсутня ціла секція `scales` не є помилкою: ваги просто не створюються;
- помилки структури кореневого XML, секції `apairy_set` або атрибута `hiveN` можуть бути критичними для читання конфігурації.

Створення початкового `mset.xml` не означає, що всі параметри матимуть універсальні значення. `UPLOAD_URL`, облікові дані FTP, контакти HX711 та частина інших полів залежать від комплектації або індивідуального налаштування пристрою.

!!! warning "Резервна копія обов'язкова"
    Не покладайтеся на автоматичне відновлення як на єдину резервну копію. Перед заміною microSD збережіть увесь каталог `/setting`, якщо картка читається.

## Безпечна заміна microSD

1. Дочекайтеся переходу пристрою в режим сну.
2. Вийміть microSD і, якщо вона читається, скопіюйте весь її вміст.
3. Підготуйте microSD відповідно до вимог конкретної апаратної версії пристрою.
4. Відновіть каталог `/setting` із перевіреної резервної копії.
5. Якщо резервної копії немає, не підставляйте калібрувальні значення ваг з іншого пристрою. Спочатку відновіть мінімальний [`mset.xml`](settings-reference.md#minimal-example), а файл вулика створіть без секції `scales` або виконайте штатне калібрування.
6. Встановіть microSD, поки пристрій спить, і дочекайтеся наступного циклу роботи.
7. Перевірте час, мережу, номери GSM, наявність датчиків, розклад і вагу.
8. Порівняйте нормалізовані XML із резервною копією: пристрій міг додати поля з резервними значеннями або переписати секції.

## Якщо конфігурація не читається

1. Перевірте, що файл має один кореневий елемент `<settings>`.
2. Перевірте точні назви `apairy_set`, `synchronize`, `sefe_start_interval` і `pecision` у трьох полях фільтрів.
3. Переконайтеся, що `hive_count` має відповідні атрибути `hive1`…`hiveN`.
4. Переконайтеся, що кожен вказаний файл `/setting/<hive>.xml` існує.
5. Не виправляйте проблему копіюванням `scales` з іншого пристрою; тимчасово приберіть секцію ваг і перевірте решту конфігурації.
6. Збережіть проблемні XML і службові журнали для діагностики.

Повний опис полів дивіться у довідниках [`mset.xml`](settings-reference.md) та [`HIVE*.XML`](hive-settings-reference.md).
