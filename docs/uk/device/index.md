# Пасічні ваги BeeApiary — електронні ваги для вулика { #beeapiary }

Пасічні ваги BeeApiary — електронні ваги для вулика, розраховані на експлуатацію на відкритому повітрі. Вони виконують вимірювання, накопичують їх на microSD і передають власнику через доступні канали зв'язку. Разом із датчиками та застосунком ваги формують розумний вулик BeeApiary для локального або віддаленого моніторингу.

Такі ваги для вулика також називають бджоловагами.

Основні складові та опції:

- вимірювання ваги до 200 кг;
- два температурні датчики;
- датчики вологості й тиску як опції;
- датчик руху та OLED-екран як опції;
- GSM, Wi-Fi і Bluetooth;
- живлення від одного або двох елементів 18650; залежно від моделі та конфігурації плати пристрій може постачатися з іншим типом батареї.

Пристрій розрахований на вуличне використання та має ступінь захисту IP65.
