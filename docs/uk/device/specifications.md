# Технічні характеристики

| Параметр | Значення |
|---|---|
| Вага | 0-200 кг, заявлена точність ±0,1 кг |
| Температура | -20…+50 °C, заявлена роздільна здатність 0,1 °C |
| Вологість, опція | 0-100%, роздільна здатність 1% |
| Тиск, опція | 50-950 мм рт. ст., заявлена точність ±1 мм рт. ст. |
| Живлення | 1 або 2 елементи 18650 |
| Заряджання | USB Type-C або сонячна панель |
| Передача | GSM, Wi-Fi, BLE |
| Локальне зберігання | microSD |
| Маса комплекту | приблизно 0,5 кг |

Автономність залежить від комплектації, стану батарей, GSM-покриття й кількості SMS. За рекомендованої конфігурації вона становить щонайменше п'ять місяців, але цей показник не гарантований для всіх умов.
