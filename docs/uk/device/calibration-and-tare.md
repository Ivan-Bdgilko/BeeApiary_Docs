# Калібрування і тарування

!!! danger "Новий пристрій не потрібно калібрувати"
    Калібрування потрібне переважно після ремонту або втрати заводських калібрувальних даних. Не запускайте його як загальний спосіб усунення проблеми з вагою.

## Калібрування

1. Від'єднайте зовнішнє живлення.
2. Установіть усі вагові датчики на твердій горизонтальній поверхні та залиште порожню платформу.
3. Підключіться до точки доступу пристрою й у його вебінтерфейсі відкрийте **Загальні налаштування → Налаштування ваги**.

    ![Кнопка налаштування ваги](../../assets/uk/device/calibration-and-tare/open-scale-settings.png){ .doc-screenshot }

4. Запустіть **Калібрування нуля** й дочекайтеся завершення, не торкаючись платформи.

    Екран показує два етапи калібрування:

    ![Етапи калібрування ваги](../../assets/uk/device/calibration-and-tare/calibration-steps.png){ .doc-screenshot }

    ![Процес калібрування нуля](../../assets/uk/device/calibration-and-tare/zero-calibration-progress.png){ .doc-screenshot }

5. Виберіть доступний еталон 500, 1000 або 5000 г і покладіть його на платформу.

    ![Вибір еталонної ваги](../../assets/uk/device/calibration-and-tare/reference-weight-selection.png){ .doc-screenshot }

6. Запустіть **Калібрування за еталоном** і дочекайтеся результату.

    ![Процес калібрування за еталоном](../../assets/uk/device/calibration-and-tare/reference-weight-calibration-progress.png){ .doc-screenshot }

    ![Результат калібрування ваги](../../assets/uk/device/calibration-and-tare/calibration-result.png){ .doc-screenshot }

## Тарування

Можна ввести відому вагу тари в грамах:

![Введення відомої ваги тари](../../assets/uk/device/calibration-and-tare/known-tare-weight-form.png){ .doc-screenshot }

Або прийняти поточну вагу платформи за нуль:

![Прийняття поточної ваги за нуль](../../assets/uk/device/calibration-and-tare/use-current-weight-as-zero.png){ .doc-screenshot }

Тарування не змінює заводський коефіцієнт калібрування.

Окремі процедури: [Тарувати ваги](../guides/tare-scales.md) і [Калібрувати ваги](../guides/calibrate-scales.md).
