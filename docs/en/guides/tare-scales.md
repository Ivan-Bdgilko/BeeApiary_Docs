# How to Tare the Scales

Taring excludes the weight of the platform or another permanent structure from measurements.

1. Connect to the web interface of the BeeApiary measuring device.
2. Open **General Settings → Scale Settings**.
3. If you know the tare weight, enter it in grams and select **Set Tare Weight**.
4. Alternatively, leave the required structure on the sensors and choose the option that accepts the current value as zero.
5. Check the reading when the operation is complete.

Result: the device subtracts the specified tare from subsequent measurements. Taring is not calibration.
