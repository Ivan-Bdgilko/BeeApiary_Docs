# How to Update the BeeApiary App

1. Open [BeeApiary on Google Play](https://play.google.com/store/apps/details?id=com.beeapiary).
2. If an update is available, tap **Update**.
3. After launching the app, check all permissions required for it to work and grant any missing permissions. Make sure the devices you added are still in the list.

Outdated APK files in [Android_Apk](https://github.com/Ivan-Bdgilko/Android_Apk) may contain only older versions. Google Play is the primary installation source.
