# Install the BeeApiary App

The BeeApiary app can work independently without beehive scales. Use it to explore the app and features that do not require automatic measurements.

A demo mode simulates the scales so you can see their data and screens without physical equipment.

1. [Install the BeeApiary app](../app/installation.md) from Google Play and grant the requested permissions.
2. In the main menu, select **Add Device or Hive**.
3. Choose a scenario:

    - [Add a hive](../app/add-hive.md) for a journal, hive state and events without physical scales.
    - Select **Add Test Data** to create a [demo hive with simulated scales](../app/add-device-or-hive/index.md#test-hive-with-simulated-scales).

Done: the app is installed and can work without scales or in demo mode. Real scales can send data through GSM, direct Wi-Fi, the apiary Wi-Fi network or Bluetooth. Compare the [ways to receive data](../system/connectivity.md).
