# How to Install Beehive Scales Under a Hive { #installing-the-device }

Place the main unit in a sheltered location and the weight sensors on firm supports.

1. Choose a sheltered location under a canopy or hive cover.
2. Position the main unit to minimize exposure to direct sun, rain and snow.
3. Place the [weight sensors](sensors.md) on firm supports in the same horizontal plane.
4. Position the temperature sensors according to the observation goal.

!!! danger
    Do not place the device or external antenna at the highest point of the apiary: lightning can irreparably damage it.

More details: [Placement](placement.md) and [Sensors](sensors.md).
