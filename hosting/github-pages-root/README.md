# Favicon для головного GitHub Pages сайту

Цей каталог не входить до MkDocs build. Він містить готову головну сторінку для `https://ivan-bdgilko.github.io/`.

## Публікація

1. Створити публічний репозиторій `Ivan-Bdgilko/ivan-bdgilko.github.io`.
2. Додати `index.html` із цього каталогу в корінь гілки `main` нового репозиторію.
3. У Settings → Pages вибрати Deploy from a branch → `main` → `/ (root)`.
4. Перевірити відкриття `https://ivan-bdgilko.github.io/` та доступність favicon.
5. Запросити повторне сканування цієї головної сторінки через URL Inspection у Google Search Console.

Головна сторінка посилається на наявну бджілку з документації. Зображення не дублюється й не змінюється. URL документації залишається незмінним.

Google використовує одну favicon на hostname, тому вона може застосовуватися до всіх проєктів на `ivan-bdgilko.github.io`. Відображення в пошуку не гарантоване та залежить від повторного сканування.

Правила: https://developers.google.com/search/docs/appearance/favicon-in-search
